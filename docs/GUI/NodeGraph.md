# ノードグラフ

## 状態

確定。

## キャンバス

- 無限キャンバス、中央原点、8 logical pxグリッドを使用する。
- グリッドスナップは既定で無効とし、ツールバーから切り替える。
- マウスホイールでカーソル位置中心にズームし、範囲は25%～200%とする。
- 中ボタンドラッグまたは `Alt + 左ドラッグ` でパンする。
- 右下にミニマップを表示し、ツールバーから非表示にできる。
- ノード位置をVJプロジェクトへ保存する。コメントボックスとグループ機能は初期対象外とする。

## ノード追加

- 主要操作は、キャンバス上の右クリックまたは `Tab` で開く検索ポップアップとする。
- ポップアップは開いたキャンバス座標へノードを追加する。
- 表示名、カテゴリ、NodeTypeIdを部分一致で検索し、表示名のファジー一致を優先する。
- 検索未入力時はRecent、Favorites、カテゴリ一覧の順で表示する。
- 上下キーで候補移動、`Enter` で追加、`Esc` で閉じる。
- SystemOwnedまたはUserAddableでない型は候補へ表示しない。
- Node Libraryは補助操作として常設可能にし、カテゴリツリー、検索、Favoritesを提供する。
- Node Libraryからのダブルクリックはキャンバス中央、ドラッグはドロップ位置へ追加する。
- 接続を空白へドロップした場合は、接続元と互換性のあるポートを持つノードだけへ絞った検索ポップアップを開く。追加後は互換ポートが1つなら自動接続し、複数なら選択を求める。
- 3D／2D合計24ノード上限へ達した場合も型を検索結果から消さず、無効候補として理由を表示する。

## 選択と編集

- 左クリックで単一選択、`Shift + 左クリック` で選択追加／解除する。
- 空白から左ドラッグして矩形選択する。
- `Ctrl + A` で全選択、`Esc` で選択解除する。
- 選択ノードはドラッグで移動し、複数選択中は相対位置を保つ。
- `Delete` で選択ノードを確認なしに削除し、Undoで復元できる。
- ProgramOutputなど削除不可ノードを含む場合、そのノードだけ残して理由をトースト表示する。
- `Ctrl + C`／`Ctrl + V`、`Ctrl + D`でコピー、貼り付け、複製する。SystemOwnedノードは複製対象外とする。
- `F` で選択へフォーカス、`Home` で全ノードを表示範囲へ収める。
- GraphEditCommandのUndo／Redoはトップバーと `Ctrl + Z`／`Ctrl + Shift + Z` から実行する。

## ノード表示

- 既定幅は220 logical px。カスタムUIまたはPreviewサムネイルを持つ場合だけ縦方向へ拡張する。
- ヘッダーは状態アイコン、表示名、カテゴリ色、折り畳み、Preview目アイコン、コンテキストメニューを持つ。
- 本体は入力ポート、簡易状態、主要パラメーター、出力ポートを上から安定順で表示する。
- ノード上へ表示する主要パラメーターはノード型が明示した最大4件までとし、その他はInspectorへ表示する。
- 折り畳み時もヘッダー、ポート、状態アイコンは残す。
- Previewノードは16:9サムネイルを表示し、ダブルクリックでPreview Viewer Host内の対応タブを開く。
- ProgramOutputは新規プロジェクトの右側中央へ置き、移動だけを許可する。

## ポートと接続

- 入力は左、出力は右へ配置する。
- 必須入力は塗りつぶしソケット、任意入力は中央が空いたリングソケットとし、文字ラベルにも `Required`／`Optional` のツールチップを付ける。
- ポート型は色と中央記号の両方で区別する。色だけに依存しない。
- ドラッグ中は互換ポートを強調し、非互換ポートを弱く表示する。
- 非互換接続はドロップ時に拒否し、カーソル付近へ短い理由を表示する。
- 接続済み入力への新規接続は確認なしで原子的に置換する。検証失敗時は旧接続を維持する。
- 暗黙変換を含む接続は破線と変換バッジで表示し、バッジのツールチップへ変換IDを表示する。
- 情報を失う変換は明示ノードだけを許可する。
- 多数のFan-outは通常時に束ね、接続または出力ポート選択中だけ接続先一覧を展開する。
- プロジェクト全体の接続数が4096へ達した場合は新規接続を拒否し、キャンバスツールバーへ上限到達を表示する。

## 状態と診断

- Blockedは橙のヘッダー境界と不足入力アイコンを表示する。
- Faultedは赤のヘッダー境界と診断件数を表示する。
- Preparingはシアンの進行アイコン、UsingFallbackは黄の入力ソケットバッジを表示する。
- UnknownNodeは元NodeTypeId、SchemaVersion、評価不能理由、`Try Restore`を本体へ表示する。
- 状態アイコンのクリックでDiagnosticsパネルを開き、そのノードでフィルターする。
- 同一フレーム境界まで適用待ちの編集は、ノードまたは接続へ最大1フレームだけ点線のPending表示を行う。
