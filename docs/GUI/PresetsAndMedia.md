# プリセットと素材

## 状態

確定。

## Presetsパネル

- プリセットは押した時点で呼び出すボタン型UIとする。選択後に別のApply操作を要求しない。
- ボタンはレスポンシブグリッドで配置し、最小幅120 logical px、最小高さ48 logical pxとする。
- カテゴリを上部のドロップダウンで絞り込み、未分類を `Uncategorized` と表示する。
- ボタンはSortIndex順に並べ、`Reorder` 有効時だけドラッグで並べ替える。
- 通常時のドラッグは呼び出しと競合するため無効とする。
- ボタン押下時は次の評価フレーム境界まで押下表示を維持し、適用成功時に短く点灯する。
- 適用失敗時は赤く点滅させず、赤い境界、エラーアイコン、トーストを表示する。
- 部分プリセットへ「現在選択中」という永続表示は行わない。適用後の個別操作で一致判定が曖昧になるためである。
- `New`、`Edit`、`Duplicate`、`Rename`、`Delete`をパネルツールバーとボタンのコンテキストメニューから提供する。

## Preset Editor

- 名前、カテゴリ、対象ツリー、Broken項目を編集する独立パネルとする。
- 左にノード／パラメーターツリー、右に取り込み済み項目と保存値を表示する。
- ノード単位の全選択／全解除を提供する。
- チェックを入れた時点のBaseValueを取り込み、EffectiveValueは取り込まない。
- `Recapture Selected` で選択項目のBaseValueだけを現在値へ更新する。
- 編集内容はDraftとして保持し、`Save Preset` 成功時だけ確定する。
- Broken項目は対象ID、保存値、理由、`Remove`を表示する。
- Broken項目を含む間は保存できるが、呼び出し不能であることを上部バナーへ表示する。

## Media Library

- Grid／Listの2表示を持ち、表示方式はユーザー設定へ保存する。
- ツールバーにImport、検索、種別フィルター、状態フィルター、表示切り替えを置く。
- Gridはサムネイル、表示名、種別、保証状態を表示する。
- Listは表示名、種別、サイズ、相対パス、色空間、Alpha、整合性状態を表示する。
- 素材選択時はパネル右側の詳細領域へMediaAssetId、相対パス、バイト数、XXH3-128、インポート設定、参照数を表示する。
- MediaAssetReference欄へのドラッグ＆ドロップでBaseValueを変更できる。
- Node Graphへドロップした場合、素材種別に対応するUserAddableノードが1種類だけなら作成して割り当て、複数なら互換ノード検索を開く。対応型がなければ拒否理由を表示する。

## インポート

- `Import` またはOSからのファイルドロップで開始する。
- 複数ファイルをキューへ追加し、パネル下部の非モーダル進行領域へファイル別進捗を表示する。
- コピー、サイズ検証、ハッシュ検証、Probeの段階を表示する。
- 保証外形式はProbe成功後に警告付き確認を出し、承認時だけ登録する。
- 同一内容でも既存素材へ自動統合しない。ハッシュ一致時は情報だけを表示して別IDで続行できる。
- Import中にパネルを閉じても処理を継続し、ステータスバーへ件数を表示する。

## 削除と差し替え

- 素材削除は必ず確認ダイアログを表示する。
- ダイアログへ参照中ノードとプリセットを列挙し、参照が多い場合は検索可能な一覧へする。
- 削除後の参照はBrokenとして保持し、自動的に別素材や元ファイルへ戻さない。
- BrokenなMediaAssetReferenceはInspector、Dashboard、Preset Editorから `Replace` を実行できる。
