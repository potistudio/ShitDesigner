# 3D描画ノード

## 状態

確定。`docs/SPECIFICATION/REQUIREMENTS.md` および関連する個別仕様に基づく初期版の3D描画ノード仕様とする。

## 確定事項

- 3D表現を映像として生成するノードである。
- 必須の主出力ポート `Image` から、映像実体の `RenderTexture` を含む `ImageFrame` を出力する。
- `Image` に加えて、任意の名前付き出力ポートを定義できる。
- 2D描画、シェーダー、プリレンダ動画の各ノードと同じノードグラフへ配置できる。
- 出力は同一グラフ内で加工・合成できる。
- Standaloneアプリの実行中に扱えるノードである。
- 新しいノード種別を追加するとき、既存グラフや保存形式の全面変更を要求しない拡張構造へ従う。
- 映像をLinear色空間で生成する。
- Premultiplied Alpha形式で映像を出力する。
- ノードインスタンスごとに専用のルート、Camera、3Dオブジェクト群を持つ独立した3D空間を所有する。
- 他の3D描画ノードのオブジェクト、ライト、Cameraを暗黙的に共有しない。
- 自身のCameraで自身の空間を描画し、出力ポートへ貸し出されたRenderTextureへ結果を書き込む。
- 共通3Dノード型の各インスタンスが、安定UUIDと生成用Prefabを持つ `Scene3DDefinition` を選択する。
- 同じ `Scene3DDefinition` または異なるDefinitionを選んだ3Dノードを複数配置でき、各インスタンスの空間と状態を分離する。
- VJプロジェクトには型ID、Definition UUIDおよびインスタンス状態を保存し、PrefabやGameObject階層そのものは保存しない。
- 共通 `NodeTypeRegistry` へ3Dカテゴリのノード型として登録する。

## 要求への対応

- `docs/SPECIFICATION/REQUIREMENTS.md` Acceptance Criteria: 「3D描画ノードがRenderTextureを出力できる」
- `docs/SPECIFICATION/REQUIREMENTS.md` Acceptance Criteria: 4種類のノードを同一グラフ内で接続し、加工・合成できる
