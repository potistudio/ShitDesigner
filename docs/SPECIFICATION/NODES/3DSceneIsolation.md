# 3D描画ノードの空間分離

## 状態

Additive Scene、ローカル3D Physicsおよび専用Unity Layerを使う具体的な分離実装まで確定。

## 確定事項

- 各3D描画ノードは、他の3D描画ノードから独立した3D空間を所有する。
- 各3D描画ノードは、専用のルート、Camera、3Dオブジェクト群を持つ。
- 各3D描画ノードのライトは、そのノードが所有する3D空間だけへ影響する。
- 他の3D描画ノードが所有するオブジェクト、ライト、Cameraを暗黙的に共有しない。
- 1つの3D描画ノードを追加、削除、複製しても、別の3D描画ノードが所有する空間を変更しない。
- 3D描画ノードは、自身のCameraで自身の空間を描画し、出力ポートへ貸し出されたRenderTextureへ結果を書き込む。
- 3D空間の状態と公開パラメーターは、ノードインスタンスごとに分離する。
- 専用Additive Sceneを `LocalPhysicsMode.Physics3D` で生成し、User Layer 8～31のプールから1つを割り当てる。
- CameraとLightのCulling Maskを割り当てLayerへ限定し、URPのRender Requestで出力Textureへ描画する。
- 3D／2D Sceneノードの合計上限は24個とする。

## 設計意図

- 3D表現モジュールを自己完結させ、ノード接続とパラメーターだけで再現できるようにする。
- ライト、Camera、オブジェクトの変更が別ノードの映像へ影響することを防ぐ。
- 同じ3D表現を複数配置し、それぞれ異なる状態で動かせるようにする。
