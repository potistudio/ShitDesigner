# アスペクト比の伝播

## 状態

Program／Preview間の優先順位、Fit／Fill／Stretchおよび余白・切り取り規則まで確定。

## 確定事項

- 同じノード出力へ異なるアスペクト比の要求が到達した場合、最も優先度が高い出力ターゲットのアスペクト比を採用する。
- Program出力は、すべてのPreview出力より高い優先度を持つ。
- ProgramとPreviewが上流ノードを共有する場合、その共有ノードはProgramが要求するアスペクト比で1回だけ評価する。
- Previewは、共有された映像を自身の表示領域へ合わせるため、終端側で `Fit`、`Fill`、`Stretch` のいずれかを適用できる。
- `Fit`、`Fill`、`Stretch` による表示調整のために、共有された上流ノードを再評価しない。
- Programと共有されないPreview専用の枝は、そのPreviewが要求するアスペクト比を上流へ伝播できる。
- アスペクト比の違いだけを理由として、同じ上流ノードを同一フレーム内で複数回評価しない。
- 各Previewノードは `Fit`、`Fill`、`Stretch` を保存パラメーターとして個別設定でき、既定値は `Fit` とする。

## 表示方式

| 方式 | 動作 |
|---|---|
| `Fit` | 映像全体を維持し、余白を許可して表示領域内へ収める |
| `Fill` | アスペクト比を維持し、表示領域を埋めるようにはみ出した部分を切り取る |
| `Stretch` | 表示領域へ合わせて縦横を独立に拡縮する |

## 設計意図

- ProgramとPreviewの共通処理を、アスペクト比ごとに重複評価しない。
- Program映像の構図と品質をPreview要求より優先する。
- Previewごとの表示目的に合わせて、終端だけで見え方を調整できるようにする。
