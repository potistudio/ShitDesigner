# 素材整合性ハッシュ

## 状態

素材ファイルの整合性確認にXXH3-128を使用する方式は確定。

## 確定事項

- 素材ファイルのハッシュ方式はxxHash Familyの `XXH3-128` とする。
- メタデータにはAlgorithm ID `xxh3_128` と128bit Digestを小文字16進数で保存する。
- 素材インポート時に一時コピー全体からDigestを計算し、コピー元の計算結果と一致してから確定する。
- プロジェクト読込時はファイルサイズを先に確認し、一致する素材だけXXH3-128を検証する。
- Digest不一致は素材破損として扱い、参照ノードをFaultedにする。
- ハッシュは破損検出とコピー確認に使用し、改ざん耐性や認証目的には使用しない。
- ProjectFormatVersion 1ではSHA-256値を保存しない。
- XXH3-128実装は公式Test Vectorで検証し、Windows x64とmacOS arm64で同じDigestになることを自動テストする。

## 設計意図

- 大容量動画の読込確認時間を短縮する。
- アルゴリズムIDを保存し、将来の形式変更を判別できるようにする。
- 非暗号ハッシュであることを用途上明示する。
