# プリセットの原子的適用

## 状態

値を補間せず原子的に適用し、非同期準備中はPreparingとして最後の正常映像を保持する方式まで確定。

## 確定事項

- プリセット呼出時は、保存されたすべての対象と値を反映前に検証する。
- 検証では、対象ノードの存在、対象パラメーターの存在、型互換、値の有効性を確認する。
- ハード範囲外の値は検証失敗にせず、対象パラメーターのハード範囲へクランプ可能な値として扱う。
- すべての対象が検証に成功した場合だけ、プリセット適用を予約する。
- プリセット値は、次のノードグラフ評価フレーム境界で一斉に反映する。
- 評価フレームの途中でプリセット値を反映しない。
- 1つでも検証に失敗した場合、プリセット内のどの値も反映しない。
- 検証失敗時は、対象パラメーターの現在値をすべて維持する。
- 検証失敗の原因として、プリセット名、対象ノード、対象パラメーター、失敗理由を操作画面へ表示する。
- プリセット適用は、複数パラメーターをまとめた1つの状態変更として扱う。
- 値の補間は行わず、フレーム境界で目標値へ即時変更する。
- プリセット値は対象パラメーターの `BaseValue` へ反映する。
- 範囲外のプリセット値は、ハード範囲へクランプした値を `BaseValue` へ反映する。
- 同じ評価フレーム境界で最新の論理コントロール値とともにスナップショット化し、合成式から `EffectiveValue` を1回再計算する。

## 設計意図

- 複数パラメーターの適用途中に、一時的な組み合わせが映像へ現れることを防ぐ。
- 一部だけ適用された、再現不能なプリセット状態を作らない。
- ライブ中でも適用失敗前の正常な状態を維持する。
- 問題のあるプリセット対象をユーザーが特定できるようにする。
