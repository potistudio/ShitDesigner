# Blocked／Faulted時の出力フォールバック

## 状態

確定。

## 確定事項

- Program出力が現在フレームの有効な映像を取得できない場合、最後の正常フレームを表示し続ける。
- 最後の正常フレームが存在しない場合、Program出力は黒い映像を表示する。
- Program映像へ診断情報を重ねない。
- 操作用Previewには、Blocked状態と原因を示すエラー表示を重ねる。
- Programが最後の正常フレームを表示していても、操作画面では更新停止中であることを確認できるようにする。
- 上流が復旧して有効な `ImageFrame` を取得した場合、ProgramとPreviewは新しい正常フレームの表示へ自動的に戻る。
- Faulted状態によってProgramまたはPreviewが有効な映像を取得できない場合も、同じ出力フォールバックを適用する。

## 設計意図

- 観客向け映像の連続性を優先する。
- 操作者には問題を隠さず、Program映像と診断表示を分離する。
