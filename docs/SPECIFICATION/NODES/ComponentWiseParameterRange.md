# Vector／Colorの成分別範囲

## 状態

`Vector2`、`Vector3`、`Vector4` および `Color` の範囲とクランプを成分ごとに扱う方式は確定。

## 役割

複数成分を持つパラメーターで、各成分に適した有効範囲と論理コントロールの可動域を定義する。

## 確定事項

- `Vector2` のハード最小値とハード最大値は、X、Yの成分ごとに定義する。
- `Vector3` のハード最小値とハード最大値は、X、Y、Zの成分ごとに定義する。
- `Vector4` のハード最小値とハード最大値は、X、Y、Z、Wの成分ごとに定義する。
- `Color` のハード最小値とハード最大値は、R、G、B、Aの成分ごとに定義する。
- 各成分の最小値は、同じ成分の最大値以下でなければならない。
- 範囲外の値は、範囲を外れた成分だけを対応する境界値へクランプする。
- 論理コントロール合成式専用の任意出力範囲も、VectorおよびColorでは成分ごとに設定する。
- 合成式専用範囲の各成分は、対応するハード範囲の内側でなければならない。
- Min／Max合成、合成式専用範囲のクランプ、ハード範囲のクランプは、すべて同じ成分対応で処理する。
- `Color` の範囲を一律の `0～1` に固定せず、各 `ParameterDefinition` が用途に応じてRGBAのハード範囲を定義する。

## 例

```text
HardMin = (-1.0, 0.0,  2.0)
HardMax = ( 1.0, 4.0, 10.0)
Input   = (-2.0, 3.0, 12.0)
Result  = (-1.0, 3.0, 10.0)
```

## 設計意図

- 位置、方向、色など、成分ごとに意味と有効範囲が異なる値を扱えるようにする。
- 1成分の範囲超過によって、範囲内にある他の成分まで変化させない。
- HDR用途を含むColorパラメーターを、不要な `0～1` 制限で失わないようにする。
