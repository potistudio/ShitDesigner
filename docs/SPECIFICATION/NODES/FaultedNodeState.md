# Faultedノード状態

## 状態

基本契約、再試行、診断フィールドおよび連続失敗時のログ抑制規則まで確定。

## 発生条件

- ノードの評価処理で例外が発生した場合、そのノードを `Faulted` 状態とする。
- 素材の読み込みやデコードなど、ノード自身の処理が失敗した場合も `Faulted` 状態とする。

## 確定事項

- `Faulted` は、入力不足を表す `Blocked` と区別する。
- `Faulted` 状態のノードは、その評価フレームの新しい出力値を生成しない。
- `Faulted` 状態のノードは、例外または失敗の原因を診断情報として保持する。
- `Faulted` ノードの出力を必須入力として必要とする下流ノードは、入力を取得できないため `Blocked` 状態になる。
- `Faulted` ノードの出力を任意入力へ接続している下流ノードは、その入力の既定値へフォールバックできる。
- 失敗した枝と依存関係のないグラフの枝は、通常どおり評価を続ける。
- `Faulted` ノードは次の評価フレームで自動的に評価を再試行する。
- 再試行に成功した場合、そのフレームから通常状態と有効な出力へ戻る。
- ノードエディターは `Faulted` 状態を `Blocked` と区別し、原因を表示する。
- FaultedがProgram出力へ影響した場合は、最後の正常フレームを表示する出力フォールバックを適用する。
- 操作用Previewには、Faulted状態と原因を示すエラー表示を重ねる。

## 設計意図

- 構成不足と実行時の故障を区別し、修正すべき原因を判断しやすくする。
- 一時的な素材読み込み失敗などから、ユーザー操作なしで復旧できるようにする。
- 1つのノードの故障によって、無関係な映像の枝まで停止することを防ぐ。
