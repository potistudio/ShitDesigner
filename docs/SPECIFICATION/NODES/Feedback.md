# Feedbackノード

## 状態

基本契約、透明黒初期値、二重バッファ、後処理コミットおよびリセット規則まで確定。

## 役割

前の評価フレームの映像を現在の評価フレームへ渡し、時間をまたぐ映像フィードバックを明示的に構成する。

## 確定事項

- ノードグラフ内の循環接続は、`Feedback` ノードを経由する場合だけ許可する。
- `Feedback` ノードは、現在の入力映像ではなく前の評価フレームで保持した映像を現在の出力として返す。
- 現在フレームの入力映像は、同一フレームの下流評価が必要とする依存関係には含めない。
- 現在フレームの入力映像は、後続フレームで出力するために保持する。
- これにより、フレームをまたぐ接続は可能にしながら、同一フレーム内の評価グラフは非循環に保つ。
- 主出力ポート `Image` から `ImageFrame` を出力する。
- 映像を受け取る入力ポートは1本の接続だけを受け入れる。
- `Feedback` ノードを経由しない循環接続は許可しない。

## 設計意図

- 残像や映像フィードバックをノードグラフ内で表現できるようにする。
- 任意の循環によって評価順序や停止条件が不明になることを防ぐ。
- 時間をまたぐ依存関係を、グラフ上で明示できるようにする。

## 接続例

`Source -> Mix -> Feedback -> Mix`

この接続では、`Feedback` が前フレームの `Mix` 結果を返すため、現在フレームの `Mix` は有限の依存関係として評価できる。
