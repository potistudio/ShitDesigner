# GraphClock

## 状態

動画再生の基準時計、時刻源、倍精度、フォーカス喪失および外部参照時刻による同期まで確定。

## 役割

時間に依存するノードへ、ノードグラフ全体で共通の論理時刻を提供する。

## 確定事項

- `VideoPlayer` ノードは、共通の `GraphClock` を再生時刻の基準として使用する。
- 各 `VideoPlayer` インスタンスの再生位置は、保存された再生状態と `GraphClock` の時刻から計算する。
- 複数の `VideoPlayer` ノードは、同じ `GraphClock` を参照できる。
- 逆引き評価の対象外になった `VideoPlayer` ノードは、動画フレームのデコードとRenderTexture更新を行わない。
- 評価対象外でも、再生中の動画の論理的な再生位置は `GraphClock` に従って進む。
- `VideoPlayer` ノードが再び評価対象になった場合、現在の論理再生位置に対応する動画フレームを取得する。
- 非表示期間のすべての中間フレームを順番にデコードして追いつくことは必須としない。
- Pause中は、`GraphClock` が進んでもそのノードの論理再生位置を進めない。
- Seek操作は、`GraphClock` に対するそのノードの再生基準位置を更新する。
- Unity `VideoPlayer` の内部クロックだけを、グラフ上の正式な再生時刻として使用しない。

## 設計意図

- Preview表示やProgram接続の有無で動画の時間軸が意図せず停止することを防ぐ。
- 非表示動画のデコード負荷を避けながら、再表示時に時間的な整合性を維持する。
- 複数動画、プリセット、将来の時間同期機能が共通時刻を利用できるようにする。
