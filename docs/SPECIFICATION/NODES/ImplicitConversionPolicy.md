# 暗黙変換ポリシー

## 状態

基本方針、初期変換、情報保持の判定基準および明示的変換ノードまで確定。

## 確定事項

- 暗黙変換として許可するのは、元の情報を失わない直接変換だけとする。
- 情報を失う変換は暗黙変換として登録しない。
- 情報を失う変換が必要な場合は、ノードグラフ上へ専用の変換ノードを明示的に配置する。
- 専用変換ノードは、通常のノードと同様にグラフおよび接続として保存する。
- 情報を失う可能性がある変換を、警告だけで暗黙的に許可する仕組みは採用しない。
- 中央の型変換レジストリは、情報を失わない1段階の暗黙変換だけを提供する。

## 設計意図

- 値の一部が失われる処理をグラフ上で確認できるようにする。
- 接続操作だけで映像や制御値の意味が意図せず変わることを防ぐ。
- 保存したグラフから、情報が失われる場所と変換方法を追跡できるようにする。

## 例

- `Vector4` から一成分だけを取り出す処理は、専用変換ノードで行う。
- 小数部分を破棄する数値変換は、専用変換ノードで行う。

正式な初期変換ノード名と丸め方式は `LossyConversionNodes.md` の契約へ従う。
