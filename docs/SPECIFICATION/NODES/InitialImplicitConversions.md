# 初期暗黙変換

## 状態

確定。

## 確定事項

初期版で異なるポート型の間に登録する暗黙変換は、次の2つだけとする。

| 変換元 | 変換先 | 規則 |
|---|---|---|
| `Color` | `Vector4` | 4つの色成分を同じ順序の4成分値として扱う |
| `Vector4` | `Color` | 4つの数値成分を同じ順序の色成分として扱う |

- 上記はそれぞれ独立した直接変換として中央の型変換レジストリへ登録する。
- 4成分の値を変更せず、型の意味だけを変換する。
- `Float` からVector型への成分複製は暗黙変換として登録しない。
- Vector型の不足成分をゼロなどで補う変換は暗黙変換として登録しない。
- `Int` と `Float` の間は暗黙変換しない。
- 上記以外の異なる初期ポート型同士は直接接続できない。
- 上記以外の型変換が必要な場合は、専用の変換ノードをグラフへ配置する。

## 設計意図

- 初期版の暗黙変換を、情報と成分をそのまま保つ表現変換だけに限定する。
- 成分の複製、補完、選択、丸めなど、結果へ意味を加える処理をグラフ上で確認できるようにする。
- 暗黙変換の利便性を残しながら、予測しにくい自動変換を避ける。
