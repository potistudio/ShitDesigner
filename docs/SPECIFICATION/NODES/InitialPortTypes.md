# 初期ポート型

## 状態

型の一覧、永続型ID、C#表現、精度およびColor契約まで確定。

## 確定事項

初期版のノード間接続で使用できるポート型は、次の8種類とする。

| ポート型 | 用途 |
|---|---|
| `ImageFrame` | RenderTextureと映像メタデータ |
| `Float` | 小数を含む単一の数値 |
| `Int` | 整数値 |
| `Bool` | 真偽値 |
| `Vector2` | 2成分の数値 |
| `Vector3` | 3成分の数値 |
| `Vector4` | 4成分の数値 |
| `Color` | 色を表す4成分の値 |

- すべての入力ポートと出力ポートは、上記いずれかの型を宣言する。
- 同じ型同士は変換なしで接続できる。
- 異なる型同士は、中央の型変換レジストリに情報を失わない直接変換が登録されている場合だけ接続できる。
- `Texture`、`Material`、`GameObject`、`String`は初期版のポート型に含めない。
- 文字列、列挙値、素材参照など、ノード間を毎フレーム流さないデータはノードパラメーターとして保持できる。
- 新しいポート型を後から追加できる構造は維持する。
- 初期版で異なる型の間に許可する暗黙変換は `Color` から `Vector4` と、`Vector4` から `Color` の2つだけとする。
- `String`、`Enum`、`MediaAssetReference` はパラメーター型として扱い、初期ポート型には含めない。

## 設計意図

- 映像処理とリアルタイムな数値制御に必要な基本型へ初期範囲を限定する。
- Unityオブジェクト参照を任意にノード間へ流し、所有関係や保存形式が複雑になることを避ける。
- 素材参照などの設定値と、フレームごとに評価される接続値を区別する。
