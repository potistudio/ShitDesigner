# 入力接続の置換

## 状態

確定。

## 確定事項

- 接続済みの入力ポートへ別の出力ポートを接続した場合、既存接続を新しい接続へ置き換える。
- 既存接続の切断と新しい接続の作成は、1つの原子的なグラフ編集操作として扱う。
- 置換処理の途中状態として、入力ポートが一時的に未接続になったグラフを評価対象へ公開しない。
- 新しい接続に対するポート型互換検査と循環検査を、既存接続を外す前に行う。
- 新しい接続が検査に失敗した場合、置換を実行せず既存接続を維持する。
- 置換に成功した後は、入力ポートへ新しい接続だけが存在する。
- 置換のたびに確認ダイアログを表示することは必須としない。

## 設計意図

- ライブ中のグラフ組み替えを1操作で行えるようにする。
- 無効な接続操作によって、正常な既存接続まで失われることを防ぐ。
- 評価処理がグラフ編集の中間状態を読み取ることを防ぐ。
