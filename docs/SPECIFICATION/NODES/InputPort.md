# 入力ポート

## 状態

基本契約、初期型、固定ポートスキーマ、接続置換およびフレーム境界反映まで確定。

## 確定事項

- 1つの入力ポートが受け入れる接続は最大1本とする。
- 1つの入力ポートへ複数の出力を同時接続することはできない。
- 複数の入力を必要とするノードは、必要な数の入力ポートを個別に定義する。
- 各入力ポートは個別の名前を持つ。
- 合成ノードが2つの映像を必要とする場合は、例として `A` と `B` のような2つの入力ポートを定義する。
- 入力の意味と順序は接続順ではなく、接続先ポートによって決まる。
- 出力ポートと同じ型、または暗黙変換可能な互換型を接続できる。
- 互換性が定義されていない型の接続は、接続操作の時点で拒否する。
- 暗黙変換を使用する接続は、中央の型変換レジストリから解決した変換IDを保持する。
- 初期版の型は `ImageFrame`、`Float`、`Int`、`Bool`、`Vector2`、`Vector3`、`Vector4`、`Color` とする。
- 接続済みの入力ポートへ新しい有効な接続を行うと、既存接続を原子的に置き換える。
- 新しい接続が型互換検査または循環検査に失敗した場合、既存接続を維持する。
- 各入力ポートは必須または任意を宣言する。
- 任意入力は、未接続時にノードが保存している既定値を使用する。
- 任意入力が接続されている場合は接続値を優先し、切断後は既定値へ戻る。
- 必須入力が未接続、または現在フレームの値を取得できない場合、ノードを `Blocked` 状態として評価しない。
- 任意入力の接続元から現在フレームの値を取得できない場合、その入力の既定値へフォールバックする。
- 任意入力の既定値は共通 `ParameterDefinition` で定義し、入力ポートから対応する `ParameterId` を参照する。
- 任意入力が接続中でも背後のパラメーター値は保持し、切断後にその値へ戻る。

## 設計意図

- 複数接続の並び順によって結果が変化する曖昧な契約を避ける。
- ノードエディター上で、各接続がどの役割を持つか分かるようにする。
- 保存時に、接続元と接続先を一意に記録できるようにする。
- 入力ごとの型検査、必須判定、既定値を定義しやすくする。
