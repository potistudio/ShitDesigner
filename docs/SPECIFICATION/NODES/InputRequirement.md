# 入力ポートの必須・任意

## 状態

基本契約、必須入力のBlocked結果および任意入力の型別既定値まで確定。

## 確定事項

- 各入力ポートは、ノード種別の定義として「必須」または「任意」のどちらかを宣言する。
- 必須入力ポートは、そのノードを正常に評価するために接続を必要とする。
- 任意入力ポートは未接続でもよく、未接続時にはノードが保持する既定値を使用する。
- 任意入力ポートが接続されている間は、接続から受け取った値を既定値より優先する。
- 任意入力ポートの接続を切断した場合、次の評価から既定値の使用へ戻る。
- 任意入力の既定値はノードの保存対象に含め、VJプロジェクトを開き直した後も復元する。
- 任意入力の既定値は通常パラメーターと同じ `ParameterDefinition` 契約を使用する。
- ノードエディターは、必須入力と任意入力をユーザーが区別できるように表示する。
- 必須入力が未接続、または現在フレームの値を取得できない場合、そのノードを `Blocked` 状態として評価しない。
- `Blocked` 状態は依存する下流へ伝播するが、独立したグラフの枝は通常どおり評価する。
- 任意入力の接続元から現在フレームの値を取得できない場合は、その入力の既定値へフォールバックし、接続先ノードの評価を続ける。

## 設計意図

- 映像など処理に不可欠な入力と、マスクや係数など省略可能な入力を同じ規則で表現する。
- 任意入力のためだけに定数ノードを配置する必要をなくす。
- 接続を外した後も、任意入力を持つノードが定義済みの値で動作を継続できるようにする。
