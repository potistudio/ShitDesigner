# 内部色空間

## 状態

内部Linear統一、外部素材解釈、Rec.709／sRGB表示およびACESトーンマッピングまで確定。

## 確定事項

- ノードグラフ内で受け渡す映像はLinear色空間へ統一する。
- 3D描画、2D描画、シェーダー、動画、加工、合成はLinear色空間で処理する。
- sRGBなどLinear以外の外部素材は、ノードグラフへ映像を出力する前にLinearへ変換する。
- ノード間接続で、映像ごとに異なる色空間を混在させない。
- `ImageFrame` が保持する映像実体はLinear色空間である。
- `Color` ポート型で映像処理へ渡す色値もLinearとして扱う。
- ProgramおよびPreviewは、終端で内部Linear映像を表示先が要求する色空間へ変換する。
- 表示色空間への変換によって、上流ノードを再評価しない。
- VJプロジェクト単位で内部HDR／LDRを選択し、新規プロジェクトはHDRを既定とする。
- HDRでは `R16G16B16A16_SFloat`、LDRでは `R8G8B8A8_UNorm` を使用する。
- HDRのProgram映像は終端でLDRへトーンマッピングする。

## 設計意図

- ブレンド、補間、照明、ポストエフェクトを物理的に一貫した空間で計算する。
- ノード接続ごとの隠れた色空間変換を避ける。
- 入力と出力の境界へ色変換責任をまとめ、各加工ノードを単純にする。
