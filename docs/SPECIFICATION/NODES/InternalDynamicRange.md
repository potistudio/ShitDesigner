# 内部ダイナミックレンジ

## 状態

基本方式、GraphicsFormat、ACESトーンマッピング、実行中変更禁止およびGPU検証まで確定。

## 確定事項

- VJプロジェクト単位で、内部映像処理をHDRまたはLDRから選択できる。
- 新規VJプロジェクトの既定値はHDRとする。
- HDRプロジェクトでは、内部RenderTextureに `R16G16B16A16_SFloat` を使用する。
- LDRプロジェクトでは、内部RenderTextureに `R8G8B8A8_UNorm` を使用する。
- 同じノードグラフ内では、プロジェクトが選択した内部形式へ統一する。
- 初期版ではノードごとにHDRとLDRを混在させない。
- HDRプロジェクトでは、0から1の範囲を超える値をノード間で保持できる。
- Program出力は最終的にLDRとする。
- HDRプロジェクトのProgram出力は、終端でHDRの内部Linear映像をLDRへトーンマッピングする。
- 内部HDR／LDR設定はVJプロジェクトの保存対象に含め、再読込時に復元する。
- 内部HDR／LDR設定は実行中に変更せず、変更にはプロジェクト再読込を要求する。
- 再読込によって内部形式を変更した場合、出力ポートへ貸し出しているRenderTextureを新しい形式へ切り替える。
- `ImageFrame` は、映像実体が使用しているGraphicsFormatを形式情報として保持する。

## 設計意図

- 発光、Bloom、加算合成、露出調整などで必要な0から1を超える値を保持できるようにする。
- 最終出力がLDRでも、出力直前まで映像情報を失わず処理できるようにする。
- 軽量なプロジェクトではLDRを選択し、VRAM使用量とメモリ帯域を削減できるようにする。
- グラフ内の形式を統一し、ノード接続ごとの暗黙なHDR／LDR変換を避ける。
