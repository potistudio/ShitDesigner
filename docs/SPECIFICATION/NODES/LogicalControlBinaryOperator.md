# 論理コントロール合成式の二項演算

## 状態

`Min` と `Max` を常に2入力の二項演算ノードとする方式は確定。

## 役割

論理コントロール合成式の構造と括弧を、曖昧さのない二分木として表現する。

## 確定事項

- 合成式の各 `Min` 演算ノードは、左辺と右辺のちょうど2つの入力を持つ。
- 合成式の各 `Max` 演算ノードは、左辺と右辺のちょうど2つの入力を持つ。
- 1入力または3入力以上の `Min`／`Max` 演算ノードは作らない。
- 3つ以上の値を同じ演算で合成する場合は、二項演算ノードを入れ子にする。
- `Min(A, B, C)` は保存せず、`Min(Min(A, B), C)` または `Min(A, Min(B, C))` のような二分木として保存する。
- 左右どちらの入力も、型検証に成功した葉または別の二項演算ノードでなければならない。
- 片方の入力が欠けた不完全な演算ノードを、有効な合成式として評価しない。
- 式の保存データは、各演算ノードの演算種別、左の子、右の子を保持する。

## 例

```text
Min
├─ Min
│  ├─ Control A
│  └─ Control B
└─ Control C
```

上記は `Min(Min(A, B), C)` を表す。

## 設計意図

- 演算ノードの形を1種類に揃え、検証、保存および編集処理を単純にする。
- 式の括弧を二分木の親子関係として明確に保存する。
- MinとMaxを混在させた場合も、ユーザーが組んだ評価構造をそのまま再現する。
