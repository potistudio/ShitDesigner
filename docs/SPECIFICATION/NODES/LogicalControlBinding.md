# 論理コントロールのターゲット割り当て

## 状態

1対多と多対1の割り当て、Min／Max式ツリー合成、明示的な `Base` 葉による基底値の参加方式、式外の出力範囲制限、対応パラメーター型、および論理コントロールの種類は確定。

## 確定事項

- 各論理コントロールは、ユーザーが設定する名前と安定した `LogicalControlId` を持つ。
- 1つの論理コントロールから、複数のノードパラメーターへ割り当てできる。
- 各ターゲットは `NodeInstanceId` と `ParameterId` で参照する。
- 各ターゲット割り当ては、論理コントロール値からパラメーター値への個別変換設定を持つ。
- 個別変換では、少なくともターゲット値の最小値と最大値を設定できる。
- 個別変換では、論理コントロール値の方向を反転できる。
- 同じ論理コントロールでも、ターゲットごとに異なる範囲と反転設定を使用できる。
- ターゲット割り当ては、物理入力デバイスから論理コントロールへの割り当てと分離して管理する。
- 物理入力デバイスの割り当てを変更しても、論理コントロールからノードパラメーターへの割り当てを維持する。
- 論理コントロール、ターゲット割り当て、個別変換設定はVJプロジェクトの保存対象に含める。
- 論理コントロールからの変更も、UIやカスタムUIと同じ共通パラメーターAPIを通して適用する。
- 1つのパラメーターへ複数の名前付き論理コントロールを割り当てできる。
- 複数の論理コントロール値は、対象パラメーターごとに `AND / Min` または `OR / Max` で合成する。
- Boolでは論理AND／OR、数値では最小値／最大値、VectorとColorでは成分ごとの最小値／最大値を使用する。
- 論理コントロール同士の値を相互同期しない。
- MinとMaxは同じパラメーターの式ツリー内で混在でき、括弧を親子関係として保存する。
- 式内の `Min` と `Max` は、どちらもちょうど2つの入力を持つ二項演算とする。
- パラメーターの保存値は `BaseValue` とし、合成式へ `Base` 葉を配置した場合だけ合成へ参加する。
- 合成結果は `EffectiveValue` とし、論理コントロールから `BaseValue` へ書き戻さない。
- 合成式は任意の定数葉を持たず、必要な値域制限は式の外側の出力最小値／最大値として保持する。
- 論理コントロールの直接ターゲットにできる型は、`Bool`、`Float`、`Int`、`Vector2`、`Vector3`、`Vector4`、`Color` とする。
- `String`、`Enum`、`MediaAssetReference` は直接ターゲットにできず、UIまたはプリセットから変更する。
- 論理コントロールは、`0.0～1.0` の正規化値を保持する `Value` と、一度の発火を表す `PresetTrigger` の2種類とする。
- パラメーターのターゲット割り当ては `Value` を対象型へ変換し、`PresetTrigger` はMin／Max合成式へ使用しない。
- 初期版の `PresetTrigger` はプリセット呼び出しだけへ割り当て、パラメーターやグラフを直接操作しない。

## 例

```text
LogicalControl: Energy
├─ Bloom.Intensity  : 0.0 -> 8.0
├─ Video.Speed      : 0.5 -> 2.0
└─ Tint.Color       : individual mapping
```

正式な変換設定は `LogicalControlValueMapping.md` の `TargetMin`、`TargetMax`、反転および型別変換規則へ従う。

## 設計意図

- 1つの物理操作から複数の演出値を連動させる。
- 物理デバイス交換時に、演出側の割り当てを作り直す必要をなくす。
- ターゲットごとの値域差を、ノードパラメーター側の実装へ持ち込まない。
