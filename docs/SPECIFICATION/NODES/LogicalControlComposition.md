# 論理コントロールの合成

## 状態

Min／Maxによる式ツリー合成、明示的な `Base` 葉による基底値の参加方式、式外の出力範囲制限、および対応パラメーター型は確定。

## 基本モデル

- 複数の論理コントロールを1つのパラメーターへ割り当てる場合、コントロール同士を相互同期せず、値を合成する。
- 論理的な `AND` を最小値 `Min` として扱う。
- 論理的な `OR` を最大値 `Max` として扱う。
- 対象パラメーターごとに、`Min` または `Max` を使って値を合成する。
- 同じパラメーター内でMinとMaxを混在でき、括弧を式ツリーの親子関係として保存する。
- `Max(Min(A, B), C)` のような合成式を構成できる。
- `Min` と `Max` は常に左右2入力の二項演算とし、3つ以上の値は演算ノードを入れ子にして合成する。
- パラメーターの `BaseValue` は、式に `Base` 葉を配置した場合だけ合成へ参加する。
- `Base` 葉を配置しない式は、論理コントロール値だけから `EffectiveValue` を生成する。
- 式に任意の定数葉は配置せず、値域制限は式の評価後に出力最小値／最大値として適用する。
- 各論理コントロールの値をターゲット割り当ての範囲と反転設定で変換した後、対象パラメーター側で合成する。
- 合成結果へ出力範囲制限を適用した値を対象パラメーターの `EffectiveValue` として共通パラメーターAPIへ渡し、`BaseValue` は変更しない。
- 論理コントロールは自身の値を維持し、他の論理コントロールの値変更によって同期更新しない。

## 型ごとの基本演算

| 型 | `AND / Min` | `OR / Max` |
|---|---|---|
| `Bool` | 論理AND | 論理OR |
| `Float` | 数値の最小値 | 数値の最大値 |
| `Int` | 整数の最小値 | 整数の最大値 |
| `Vector2` | 成分ごとの最小値 | 成分ごとの最大値 |
| `Vector3` | 成分ごとの最小値 | 成分ごとの最大値 |
| `Vector4` | 成分ごとの最小値 | 成分ごとの最大値 |
| `Color` | RGBA成分ごとの最小値 | RGBA成分ごとの最大値 |

- `Bool` は `false = 0`、`true = 1` としたMin／Maxと整合する論理結果を使用する。
- `String`、`Enum`、`MediaAssetReference` は合成対象にしない。
- `Min` と `Max` は、同じ演算内で論理コントロールの登録順に結果を依存させない。
- 同じ評価フレームで使用するすべてのコントロール値を収集してから、パラメーターの実効値を1回更新する。

## 設計意図

- BoolのAND／ORと連続値のMin／Maxを、同じ合成概念で扱う。
- 複数入力のどれが最後に更新されたかに依存しない結果を作る。
- 連続値を乗算で不自然に減衰させたり、加算で範囲外へ膨張させたりせずに複数操作を合成する。
