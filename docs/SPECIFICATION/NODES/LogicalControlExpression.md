# 論理コントロール合成式

## 状態

Min／Max式ツリー、パラメーターの基底値を明示的な `Base` 葉として含める方式、演算ノードを二項演算とする方式、および式外の出力範囲制限は確定。

## 役割

複数の論理コントロール値を、AND／ORに対応するMin／Maxの式ツリーとして合成し、1つのパラメーター実効値を生成する。

## 確定事項

- 複数の論理コントロールを割り当てるパラメーターは、Min／Maxの式ツリーを持つことができる。
- 式の論理コントロール葉は、ターゲット範囲と反転設定を適用した `Value` 論理コントロールの値を参照する。
- `PresetTrigger` 論理コントロールは式の葉に使用しない。
- 式の葉には、対象パラメーターの保存値である `BaseValue` を参照する `Base` も配置できる。
- `Base` 葉を配置した場合だけ `BaseValue` が合成へ参加し、配置しない場合は論理コントロール値だけで実効値を決める。
- 式には任意の固定値を表す `Constant` 葉を配置しない。
- 式の演算ノードは `Min` または `Max` とする。
- 各 `Min`／`Max` 演算ノードは、左辺と右辺のちょうど2つの入力を持つ。
- 3つ以上の値を合成する場合は、二項演算ノードを入れ子にする。
- `Min` は論理AND、`Max` は論理ORに対応する。
- MinとMaxを同じ式内へ混在できる。
- 式ツリーの親子関係によって括弧と評価順序を明示する。
- `Max(Min(A, B), C)` と `Min(A, Max(B, C))` を異なる式として保存する。
- 式内の値は対象パラメーターと同じ型、またはターゲット変換後に同じ型になる必要がある。
- Boolでは論理AND／OR、数値では最小値／最大値、VectorとColorでは成分ごとの最小値／最大値を使用する。
- 各評価フレームで使用する論理コントロール値を先に確定し、そのスナップショットから式を1回評価する。
- 同じ評価フレーム境界で更新後の `BaseValue` も確定し、論理コントロール値と同じスナップショットへ含める。
- すべての式を評価して `EffectiveValue` を確定してから、ノードグラフの評価を開始する。
- 式の評価途中の値をパラメーターへ反映せず、最終結果だけを共通パラメーターAPIへ渡す。
- 式の最終結果は `EffectiveValue` へ反映し、`BaseValue` へ書き戻さない。
- 値域制限が必要な場合は、式の評価後に式外の出力最小値／最大値を適用し、その結果を `EffectiveValue` とする。
- 合成式は対象パラメーターの割り当て情報としてVJプロジェクトへ保存し、再読込時に復元する。
- 論理コントロールの登録順または更新順ではなく、保存された式ツリーだけで結果を決める。

## 例

```text
Max
├─ Min
│  ├─ Control A
│  └─ Control B
└─ Base
```

上記は `Max(Min(A, B), Base)` を表す。

## 設計意図

- ANDとORを組み合わせるのと同じ考え方で、連続値のMin／Maxを構成できるようにする。
- 暗黙の演算優先順位を使わず、結果をグラフ構造から再現できるようにする。
- コントロールの更新順によって結果が変わることを防ぐ。
