# 論理コントロール合成式の検証

## 状態

式の有効条件、編集途中の扱い、参照切れおよびUI表示は確定。

## 有効な式

- 式は対象パラメーターと互換性のある型を返さなければならない。
- 式は少なくとも1つの `Value` 論理コントロール葉を含まなければならない。
- `Base` 葉は1つの式へ最大1個まで配置できる。
- `Constant` 葉は使用しない。
- 各 `Min`／`Max` は左と右の2入力を必須とする。
- 葉または子が欠けた式、型不一致の式、循環する式は無効とする。

## 編集と適用

- 式編集UIは二分木をそのまま表示し、`Min`／`Max` の変更、左右の入れ替え、葉の差し替えを行える。
- 同種演算の入れ子も省略表示せず、保存される括弧構造を見せる。
- 編集途中の不完全な式はUI内のドラフトとして保持できるが、VJプロジェクトの有効式として保存しない。
- 編集確定時に式全体を検証し、成功した場合だけフレーム境界で旧式と置き換える。
- 検証失敗時は旧式を維持し、失敗した演算または葉へ型と理由を表示する。

## 参照切れ

- 参照する `Value` 論理コントロールが削除されても葉を `Broken` として保持する。
- `Broken` 葉を含む式は評価せず、そのパラメーターの `EffectiveValue` を安全な `BaseValue` へフォールバックする。
- 同じ `LogicalControlId` がUndoで復元した場合は自動的に式を再検証し、有効なら復帰する。

## クランプ表示

- 合成式専用範囲またはハード範囲で値が変化したフレームは、`EffectiveValue` モニターへ黄色のクランプ表示を出す。
- 表示にはクランプ前とクランプ後の値、および適用された範囲の種類を確認できる詳細表示を付ける。
- 毎フレームのクランプをエラーログへ記録しない。

## 設計意図

- 不完全な編集状態を実行中の映像へ反映しない。
- 式の意味をUI上の二分木と保存データで一致させる。
- 参照切れをデータ消失ではなく修復可能な状態として扱う。
