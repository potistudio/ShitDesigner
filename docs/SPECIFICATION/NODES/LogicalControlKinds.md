# 論理コントロールの種類

## 状態

論理コントロールを `Value` と `PresetTrigger` の2種類に分け、初期版の `PresetTrigger` をプリセット呼び出し専用とする方式は確定。

## 共通事項

- すべての論理コントロールは、ユーザーが設定する名前と安定した `LogicalControlId` を持つ。
- 各論理コントロールは、作成時に `Value` または `PresetTrigger` の種類を持つ。
- 物理入力から論理コントロールへの割り当てと、論理コントロールからパラメーターまたはプリセットへの割り当ては分離する。
- 論理コントロールの定義と割り当てはVJプロジェクトへ保存し、再読込時に復元する。

## Value

- `Value` 論理コントロールは、正規化された `Float` 値を持つ。
- 値域は `0.0～1.0` とする。
- 範囲外の物理入力値は、論理コントロールへ反映する前に `0.0～1.0` へ正規化またはクランプする。
- `Value` は最新値を保持し、次の値が届くまで同じ値を維持する。
- `Value` から対象パラメーター型への変換は、パラメーターごとのターゲット割り当てが行う。
- Min／Max合成式の論理コントロール葉は、ターゲット変換後の `Value` を参照する。

## PresetTrigger

- `PresetTrigger` 論理コントロールは、持続する数値ではなく一度の発火を表す。
- `PresetTrigger` は `0.0～1.0` の現在値を持たず、Min／Max合成式の葉には使用しない。
- 物理入力側の具体的な信号形式を、ControlMappingが1回の論理的な発火へ変換する。
- 発火は評価フレーム境界で処理する。
- 初期版で `PresetTrigger` が直接実行できる操作は、プリセット呼び出しだけとする。
- `PresetTrigger` はパラメーター、動画Transport、グラフ構造または出力を直接操作しない。
- 1つの `PresetTrigger` に割り当てられるプリセットは最大1つとし、複数の `PresetTrigger` が同じプリセットを参照することは許可する。

## 設計意図

- ノブやフェーダーの連続操作と、ボタンによる一度きりの操作を同じ値モデルへ押し込まない。
- 物理デバイス固有の値域を論理コントロール層で正規化し、演出側の割り当てを再利用できるようにする。
- VectorやColorなどへの変換方法をターゲット側へ置き、1つの `Value` を複数形式のパラメーターへ割り当てられるようにする。
