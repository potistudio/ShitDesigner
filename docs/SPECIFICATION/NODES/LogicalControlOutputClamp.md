# 論理コントロール合成式の出力範囲制限

## 状態

定数葉を式へ追加せず、`ParameterDefinition` のハード範囲内に、式外の任意の出力範囲制限を持たせる方式は確定。

## 役割

Min／Max合成式の構造を論理コントロールと `Base` の組み合わせに限定しながら、最終的な `EffectiveValue` を安全な範囲へ制限する。

## 確定事項

- 合成式の葉として任意の固定値を配置する `Constant` 葉は設けない。
- 値域をさらに狭める場合は、合成式の外側に任意の出力最小値と出力最大値を設定する。
- 出力範囲制限は対象パラメーターの合成式割り当てに属する。
- 出力範囲制限は、式ツリーを最後まで評価した後に1回だけ適用する。
- 範囲制限後の値を、そのフレームの `EffectiveValue` とする。
- 出力最小値と出力最大値は、対象パラメーターと同じ型に対応する値として検証する。
- 出力最小値と出力最大値は、`ParameterDefinition` のハード範囲内でなければならない。
- 最小値が最大値を上回る設定は無効とし、有効な合成式設定として適用しない。
- 合成式専用の範囲を省略した場合も、`ParameterDefinition` のハード範囲は常に適用する。
- 出力範囲制限の設定は合成式とともにVJプロジェクトへ保存し、再読込時に復元する。
- 論理コントロールごとのターゲット変換範囲と、合成後の出力範囲制限は別の設定として扱う。
- VectorおよびColorの出力最小値と出力最大値は成分ごとに設定し、各成分を独立してクランプする。

## 評価順序

```text
論理コントロールごとのターゲット変換
  ↓
Min／Max式ツリーを評価
  ↓
出力最小値／最大値で範囲制限
  ↓
ParameterDefinitionのハード範囲を保証
  ↓
EffectiveValue
```

## 設計意図

- 式ツリーの葉を、値の入力元である論理コントロールと `Base` だけに限定する。
- `Max(Control, 0.2)` のような定数を含む式を作らず、値域の目的を専用設定として明確にする。
- 入力ごとのマッピング範囲と、合成結果全体の安全な値域を独立して調整できるようにする。
