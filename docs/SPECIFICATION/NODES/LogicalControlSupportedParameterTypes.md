# 論理コントロール対応パラメーター型

## 状態

論理コントロールから直接操作できるパラメーター型と、対象外の型は確定。

## 役割

Min／Max合成とターゲット変換が定義できる型だけを論理コントロールへ割り当て、意味の曖昧な型変換を防ぐ。

## 対応型

論理コントロールから直接操作できる型は、次の7種類とする。

- `Bool`
- `Float`
- `Int`
- `Vector2`
- `Vector3`
- `Vector4`
- `Color`

## 対象外の型

次の3種類は、論理コントロールの直接ターゲットに指定できない。

- `String`
- `Enum`
- `MediaAssetReference`

## 確定事項

- 対応型だけが、論理コントロールのターゲット割り当てとMin／Max合成式を持てる。
- `String`、`Enum`、`MediaAssetReference` に対するMin／Max演算は定義しない。
- 対象外の型へ論理コントロールを直接割り当てる操作は、設定時に拒否する。
- 対象外の型は、標準UI、カスタムUIまたはプリセットによって `BaseValue` を変更する。
- 対象外の型は合成式を持たないため、`EffectiveValue` は `BaseValue` と同じ値になる。
- 論理コントロールからプリセットを呼び出し、そのプリセットを通して対象外の型を変更することは許可する。これは直接ターゲット割り当てとは区別する。
- 対応可否はパラメーター型から決定し、ノード型ごとに異なる暗黙ルールを設けない。

## 設計意図

- 文字列、選択肢および素材参照に対して、意味の不明確な大小比較や連続値変換を行わない。
- 論理コントロール合成式の型検証を単純で再現可能にする。
- 素材切り替えなどの離散的な状態変更は、原子的に適用できるプリセットへ任せる。
