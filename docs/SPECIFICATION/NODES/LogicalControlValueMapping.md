# Value論理コントロールのマッピング

## 状態

初期版の `Value` 論理コントロールの初期値、正規化および各パラメーター型への変換規則は確定。

## Value状態

- `Value` は `Float` の正規化値 `0.0～1.0` を保持する。
- 初期値は `0.0` とする。
- VJプロジェクトには初期値を保存するが、実行中に物理入力から受け取った最新値は保存しない。
- プロジェクト読込時は初期値から開始し、接続済み物理入力の次回更新を待つ。

## 物理入力からの正規化

- ControlMappingは `RawMin`、`RawMax`、`Invert` を持つ。
- `RawMin < RawMax` を必須とする。
- 生値を `RawMin～RawMax` から `0.0～1.0` へ線形変換し、範囲外をクランプする。
- `Invert` が有効な場合は、正規化後に `1.0 - value` を適用する。
- 初期版ではデッドゾーン、加速、任意カーブを設けない。

## ターゲット変換

- 各ターゲット割り当ては、対象型と同じ型の `TargetMin` と `TargetMax` を持つ。
- `TargetMin` は `TargetMax` 以下でなければならない。
- ターゲット側の反転は、補間係数へ `1.0 - value` を適用する。
- `Float` は `Lerp(TargetMin, TargetMax, value)` とする。
- `Int` は補間結果を0から遠ざかる方式で四捨五入し、`Int32`へクランプする。
- `Bool` は `value >= 0.5` を `true` とする。反転時は判定前に値を反転する。
- Vectorは全成分を同じ係数で、成分別の `TargetMin` から `TargetMax` へ線形補間する。
- `Color` はLinear RGBAの各成分を同じ係数で補間する。
- 変換後に合成式を評価し、式外クランプと `ParameterDefinition` のハード範囲を順に適用する。

## 参照切れ

- 対象ノードまたはパラメーターが削除されても、割り当てデータは削除せず `Broken` として保持する。
- `Broken` 割り当ては評価せず、操作画面に対象IDと理由を表示する。
- Undoまたは再読込で同じIDの対象が復元した場合は、自動的に有効へ戻す。

## 設計意図

- 物理デバイス固有の値域と、演出パラメーター固有の値域を分離する。
- 初期版は線形変換だけに限定し、結果を予測しやすくする。
- 参照切れによってユーザーのマッピング設定を失わないようにする。
