# MediaAssetカタログ

## 状態

素材ID、コピー先、相対参照、整合性検証および初期対応形式は確定。

## 識別と保存

- 各素材はUUID v4の `MediaAssetId` を持つ。
- ファイルは `Assets/{MediaAssetId}/source.ext` へコピーする。
- `project.json` はプロジェクトルートからの相対パスだけを保存し、元ファイルの絶対パスを保存しない。
- メタデータは表示名、素材種別、相対パス、バイト数、XXH3-128、インポート色空間、Alpha解釈を持つ。
- 素材参照はパスではなく `MediaAssetId` を使用する。

## インポート

- コピーを一時ファイルへ行い、サイズとXXH3-128を確認してから素材カタログへ追加する。
- 同じ内容の素材を再インポートしても別の `MediaAssetId` を作れる。自動重複排除は行わない。
- 素材削除は参照中ノードとプリセットを事前表示し、明示確認後にだけ行う。
- 削除後の参照はBrokenとして保持し、別素材へ差し替え可能にする。

## 初期保証形式

- 静止画はPNGとJPEGを保証する。PNGはStraight Alpha、JPEGは不透明として取り込む。
- Windows 10／11 x64の動画は、H.264を格納したMP4を不透明動画の保証形式とする。
- Alpha付き動画はVP8を格納したWebMを保証形式とする。
- Hap動画はMOVコンテナのHap、Hap Alpha、Hap Q、Hap Q Alphaを保証形式とする。
- 音声トラックは初期版では再生せず無視する。
- 上記以外はインポート時のProbeに成功した場合だけ試験的素材として登録し、保証対象外表示を付ける。

## 欠落と破損

- 読込時にファイル存在、サイズ、XXH3-128を検証する。
- 欠落または不一致の素材を参照するノードはFaultedとし、素材IDと相対パスを診断する。
- 元ファイルへ自動的に戻らない。

## 設計意図

- プロジェクトフォルダーだけで別PCへ移動できるようにする。
- ファイル名変更とノード参照を分離する。
- 初期保証コーデックを絞り、環境依存の再生失敗をインポート時に見つける。
