# 任意入力のフォールバック

## 状態

確定。

## 発生条件

任意入力ポートに接続は存在するが、その接続元から現在フレームの有効な値を取得できない場合に適用する。

## 確定事項

- 任意入力の接続元が `Blocked` の場合、その任意入力は保存済みの既定値へフォールバックする。
- フォールバックした任意入力は、未接続時と同じ既定値をノード評価へ渡す。
- 任意入力のフォールバックだけを理由として、接続先ノードを `Blocked` 状態にしない。
- 接続先ノードは、他の必須入力が利用可能であれば通常どおり評価を続ける。
- 過去フレームで接続元から取得した値は保持せず、現在の既定値を使用する。
- 接続は削除せず維持する。
- 接続元が有効な値を再び出力した次の評価フレームから、接続値の使用へ自動的に戻る。
- ノードエディターは、任意入力がフォールバック中であることと、その原因を表示する。

## 設計意図

- 省略可能な入力の一時的な問題によって、下流の映像生成全体が停止することを防ぐ。
- 古い値を暗黙的に使い続けず、未接続時と同じ予測可能な状態へ戻す。
- 接続を維持し、上流が復旧したときにユーザー操作なしで通常状態へ戻せるようにする。
