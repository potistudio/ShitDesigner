# 出力ポートの分岐

## 状態

確定。

## 確定事項

- 1つの出力ポートを複数の入力ポートへ接続できる。
- 分岐のために専用の `Split` ノードを配置する必要はない。
- 同一フレーム内では、出力元ノードを分岐先ごとに再評価しない。
- すべての接続先は、出力元ノードがそのフレームで生成した同じ評価結果を受け取る。
- 接続先ノードは入力値を読み取り専用として扱い、共有された入力値を変更しない。
- `ImageFrame` の接続先は、共有された入力RenderTextureへ書き込まず、自身の出力用RenderTextureへ処理結果を書き込む。
- 出力ポートの接続数に、ノード種別ごとの固定上限は設けない。

## 設計意図

- 同じ映像や制御値をProgram、Preview、加工ノードなどへ簡単に分配できるようにする。
- 分岐によるノード評価と映像生成の重複を防ぐ。
- 分岐専用ノードによってグラフが不要に大きくなることを避ける。
- 接続先による入力値の変更が、別の分岐先へ影響することを防ぐ。
