# パラメーターのフレーム境界スナップショット

## 状態

UI、プリセットおよび論理コントロールの変更を評価フレーム境界で確定し、実効値を1回だけ計算する方式は確定。

## 役割

1つの評価フレーム内に複数経路から届く値変更をまとめ、ノードグラフ全体が一貫したパラメーター状態を使用できるようにする。

## 確定事項

- UI、カスタムUI、プリセットおよび論理コントロールから届いた変更は、次の評価フレーム境界まで収集する。
- 評価フレームの途中では、収集中の変更をノード評価へ反映しない。
- 評価フレーム境界で、UI、カスタムUIおよびプリセットによる更新後の `BaseValue` を確定する。
- 同じ境界で、各 `Value` 論理コントロールが持つ最新値を確定する。
- `PresetTrigger` 論理コントロールの発火も評価フレーム境界で処理するが、パラメーター合成用の値スナップショットには含めない。
- 確定した `BaseValue` と論理コントロール値から、そのフレーム用の変更されないスナップショットを作る。
- 各パラメーターの合成式は、このスナップショットだけを使って1回評価する。
- 合成式の結果をそのフレームの `EffectiveValue` として確定してから、ノードグラフの評価を開始する。
- 同じフレーム内のすべてのノード評価は、確定済みの同じ `EffectiveValue` を使用する。
- 合成式の評価途中の値や、イベントごとの一時的な値を映像へ反映しない。
- プリセットはプリセット内の全対象を原子的に `BaseValue` へ反映した後、同じ境界で `EffectiveValue` の再計算に参加する。

## 評価順序

```text
変更を収集
  ↓
評価フレーム境界
  ↓
BaseValueと論理コントロール値を確定
  ↓
フレーム用スナップショットを作成
  ↓
全EffectiveValueを1回計算
  ↓
ノードグラフを評価
```

## 設計意図

- 同じフレームにUI操作と物理入力が届いても、到着途中の組み合わせを映像へ出さない。
- ノードの評価順によって参照するパラメーター値が変わることを防ぐ。
- 1フレーム内で同じ合成式を何度も再評価する必要をなくす。
