# パラメーターのハード範囲と合成式クランプ

## 状態

`ParameterDefinition` のハード範囲を常に守り、その内側へ合成式専用の任意範囲を設定できる方式、および範囲外の値を境界へクランプする方式は確定。

## 役割

ノード実装が許容する絶対的な値域と、演出ごとに論理コントロールの可動域を狭める設定を分離する。

## 確定事項

- 範囲を持つパラメーターでは、`ParameterDefinition` が有効値の最小値と最大値をハード範囲として定義する。
- `BaseValue` と `EffectiveValue` は、どちらも `ParameterDefinition` のハード範囲を越えてはならない。
- 論理コントロール合成式には、ハード範囲の内側へ任意の出力最小値と出力最大値を設定できる。
- 合成式専用の出力範囲は省略可能とする。
- 合成式専用の範囲を省略した場合も、`ParameterDefinition` のハード範囲は常に適用する。
- 合成式専用の出力最小値は、ハード範囲の最小値以上でなければならない。
- 合成式専用の出力最大値は、ハード範囲の最大値以下でなければならない。
- 合成式専用の最小値が最大値を上回る設定は無効とする。
- 合成式を評価した後、任意の合成式専用範囲で制限し、最後にハード範囲を保証した値を `EffectiveValue` とする。
- ハード範囲はノード型のスキーマに属し、合成式専用範囲はノードインスタンスの論理コントロール割り当てに属する。
- ハード範囲の変更はノード型の `SchemaVersion` と状態移行の対象とする。
- ハード範囲外の入力値は拒否せず、最も近いハード最小値またはハード最大値へクランプする。
- VectorおよびColorのハード範囲と合成式専用範囲は成分ごとに定義し、各成分を独立してクランプする。

## 評価順序

```text
Min／Max式ツリーを評価
  ↓
合成式専用の任意範囲で制限
  ↓
ParameterDefinitionのハード範囲を保証
  ↓
EffectiveValue
```

## 設計意図

- ノードが処理できない値を、UI、プリセットまたは論理コントロールから渡さない。
- ノード型の安全な値域を変えずに、演出単位で操作範囲だけを狭められるようにする。
- 絶対的な制約とライブ操作上の制約を、異なる保存責務として扱う。
