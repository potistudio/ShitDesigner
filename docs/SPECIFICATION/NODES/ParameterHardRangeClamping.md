# パラメーターのハード範囲クランプ

## 状態

ハード範囲外の値を拒否せず、最も近い境界値へクランプする方式と、Vector／Colorを成分ごとに処理する方式は確定。

## 役割

UI、プリセットおよび論理コントロールなど、値の入力経路にかかわらずパラメーターを有効範囲へ収める。

## 確定事項

- `ParameterDefinition` のハード範囲外にある値は、エラーとして拒否せず範囲内へクランプする。
- ハード最小値未満の値はハード最小値にする。
- ハード最大値を超える値はハード最大値にする。
- UIおよびカスタムUIからの `BaseValue` 更新に同じクランプ処理を適用する。
- プリセットからの `BaseValue` 更新に同じクランプ処理を適用する。
- 論理コントロール合成式から生成した値に同じクランプ処理を適用する。
- クランプ後の値を正式な `BaseValue` または `EffectiveValue` として扱う。
- 範囲外だった元の値を、パラメーター値またはプリセット適用後の値として保持しない。
- 型不一致、数値として無効な値、対象不明など、範囲超過以外の検証エラーはクランプで解決せず拒否する。
- `Vector2`、`Vector3`、`Vector4` および `Color` は、範囲を外れた成分だけを対応する最小値または最大値へクランプする。
- プリセットの事前検証では範囲外の値をクランプ可能な値として扱い、他の検証に成功すればクランプ後の値を原子的に適用する。

## 例

ハード範囲が `0.0～1.0` の場合：

```text
-0.2 → 0.0
 0.6 → 0.6
 1.4 → 1.0
```

## 設計意図

- ライブ操作中に一時的な範囲超過が発生しても、映像更新全体を失敗させない。
- 入力経路ごとに範囲外の扱いが変わることを防ぐ。
- ノードへ渡る値が常に実装上の有効範囲内にあることを保証する。
