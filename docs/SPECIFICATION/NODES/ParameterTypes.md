# 初期パラメーター型

## 状態

型の一覧、C#表現、精度、IDおよび基本検証規則まで確定。

## 確定事項

初期版の `ParameterDefinition` で使用できる型は、次の10種類とする。

| パラメーター型 | 用途 |
|---|---|
| `Float` | 小数を含む単一の数値 |
| `Int` | 整数値 |
| `Bool` | 真偽値 |
| `Vector2` | 2成分の数値 |
| `Vector3` | 3成分の数値 |
| `Vector4` | 4成分の数値 |
| `Color` | Linear色空間の色値 |
| `String` | テキスト設定値 |
| `Enum` | ノード型定義が提供する選択肢 |
| `MediaAssetReference` | VJプロジェクト内の素材参照 |

- `ImageFrame` はパラメーター型に含めず、ポート接続でだけ受け渡す。
- `Texture`、`Material`、`GameObject`などのUnityオブジェクト参照を、汎用パラメーター値として保存しない。
- 任意のJSONオブジェクトをパラメーター値として許可しない。
- 各パラメーター値は、宣言された型に従って検証、保存、復元する。
- 部分プリセットは、上記型のパラメーター値を型情報付きで保存する。
- 名前付き論理コントロールから直接変更できる型は、`Bool`、`Float`、`Int`、`Vector2`、`Vector3`、`Vector4`、`Color` とする。
- `String`、`Enum`、`MediaAssetReference` は論理コントロールの直接ターゲットにせず、UIまたはプリセットから変更する。
- 新しいパラメーター型を追加する場合は、保存、検証、プリセット、UI、状態移行の対応を明示的に追加する。

## ポート型との違い

- パラメーター型は、ノード設定とライブ操作値として保存できる値を表す。
- ポート型は、ノード評価時にノード間を流れる値を表す。
- `String`、`Enum`、`MediaAssetReference` は初期パラメーター型だけに含める。
- `ImageFrame` は初期ポート型だけに含める。
