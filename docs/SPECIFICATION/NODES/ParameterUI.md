# パラメーターUI

## 状態

共通UIとカスタムUIの併用、基底値と実効値の併記、メタデータ、レイアウトおよびFactory APIまで確定。

## 共通UI

- Standaloneアプリは、`ParameterDefinition` の型とメタデータから標準パラメーターUIを生成する。
- 新しいノード型は、カスタムUIを実装しなくても標準UIで全公開パラメーターを編集できる。
- 標準UIからの変更は、共通パラメーターAPIを通して `BaseValue` へ反映する。
- 標準UIは、パラメーターの型に応じた操作部品を使用する。
- 標準UIは `BaseValue` を編集可能な操作欄として表示する。
- 標準UIは `EffectiveValue` を読み取り専用モニターとして併記する。
- 合成式がない場合も両方を表示し、同じ値であることを確認できるようにする。

## カスタムUI

- 特殊な操作表示が必要なノード型は、カスタムパラメーターUIを提供できる。
- カスタムUIは、特定パラメーターの標準表示を置き換える、または標準UIを補助できる。
- カスタムUIも、共通パラメーターAPIを通して値を読み書きする。
- カスタムUIも `BaseValue` と `EffectiveValue` の区別を維持し、`EffectiveValue` を直接編集しない。
- カスタムUIがノード実装のフィールドを直接変更し、保存、プリセット、論理コントロールを迂回することは許可しない。
- カスタムUIが利用できない場合でも、標準UIへフォールバックしてパラメーターを編集できるようにする。

## ParameterDefinitionメタデータ

標準UI生成のため、型に応じて次の情報を定義できる構造とする。

- 表示名、説明、表示順、グループ
- 数値のハード最小値、ハード最大値、刻み幅、単位
- VectorおよびColorの成分ラベルと成分別範囲
- Stringの表示方法と入力制限
- Enumの安定した選択肢IDと表示名
- MediaAssetReferenceで選択できる素材種別

必須項目、既定値および表示規則は `ParameterUIContract.md` へ従う。

## 設計意図

- 新しいノード型を追加するとき、基本的な編集UIを毎回実装する必要をなくす。
- 特殊な映像表現では、標準スライダーだけに制限されない操作UIを提供できるようにする。
- UI経路によって保存やライブ操作の挙動が変わることを防ぐ。
