# パラメーターの基底値と実効値の表示

## 状態

`BaseValue` の編集欄と `EffectiveValue` の読み取り専用モニターを併記する方針は確定。

## 役割

ユーザーが設定して保存される値と、論理コントロール合成後にノードが実際に使用する値を、パラメーターUI上で同時に確認できるようにする。

## 確定事項

- パラメーターUIは `BaseValue` と `EffectiveValue` の両方を表示する。
- `BaseValue` は編集可能な操作欄として表示する。
- `EffectiveValue` は読み取り専用モニターとして表示する。
- UI操作は `BaseValue` だけを変更し、`EffectiveValue` を直接編集しない。
- `EffectiveValue` モニターは、論理コントロール合成後にノード評価で使用される値を表示する。
- 論理コントロール合成式がない場合も両方を表示し、同じ値であることを確認できるようにする。
- 標準UIはすべての公開パラメーターにこの表示方式を適用する。
- カスタムUIも `BaseValue` と `EffectiveValue` の区別を維持し、実効値を編集可能な保存値として扱わない。
- `EffectiveValue` の表示更新によって `BaseValue`、プリセットまたはプロジェクト保存データを変更しない。

## 表示概念

```text
Intensity
├─ Base      [ 0.50 ]  ← 編集可能
└─ Effective [ 0.82 ]  ← 読み取り専用
```

正式な行構造、更新頻度およびカスタムUI規則は `ParameterUIContract.md` へ従う。

## 設計意図

- 手動設定値を確認しながら、ライブ制御によって実際に使われている値も監視できるようにする。
- 実効値を操作したつもりで保存値を意図せず上書きすることを防ぐ。
- 合成式の有無によってUIの意味が変わらないようにする。
