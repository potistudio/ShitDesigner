# 部分プリセット

## 状態

確定。次の評価フレーム境界で原子的に適用し、対象欠落時は全体を適用しない。

## 確定事項

- プリセットごとに、保存対象とするノードパラメーターをユーザーが選択する。
- プリセットは、選択されたパラメーターの参照と値だけを保存する。
- プリセットに含まれていないパラメーターは、プリセット呼出時の現在値を維持する。
- 同じノードの一部パラメーターだけをプリセットへ含めることができる。
- 複数ノードから選択したパラメーターを、1つのプリセットへ含めることができる。
- `VideoPlayer` の `MediaAsset`、`Playing`、`Playhead`、`Speed`、`Loop` は、それぞれ個別にプリセット対象へ選択できる。
- 動画の `Playhead` を選択していないプリセットは、現在の再生位置を変更しない。
- プリセット対象の選択状態はプリセット本体の一部としてVJプロジェクトへ保存する。
- ノード型定義が、すべてのプリセットで共通の対象パラメーターを固定する方式にはしない。
- 呼出時にすべての選択対象を検証し、次の評価フレーム境界で値を一斉に反映する。
- 対象ノードまたはパラメーターが1つでも見つからない場合、プリセット全体を適用しない。

## 設計意図

- ライブ操作中の値を維持しながら、必要な演出値だけを切り替えられるようにする。
- 動画位置、速度、エフェクト量などを、用途に応じて独立したプリセットへ分けられるようにする。
- 全パラメーターの意図しない巻き戻りを防ぐ。
