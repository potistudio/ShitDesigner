# ポート型互換

## 状態

基本方針、初期互換型、変換ID、表示および欠落時の扱いまで確定。

## 確定事項

- 各入力ポートと出力ポートはデータ型を持つ。
- 同じ型の出力ポートと入力ポートは、そのまま接続できる。
- 型が異なっていても、互換性が定義されている組み合わせは接続できる。
- 互換型の接続では、出力値を入力ポートが要求する型へ暗黙変換する。
- 互換性が定義されていない型同士は接続できない。
- 不正な型の接続は、ノード評価時まで保留せず接続操作の時点で拒否する。
- 情報を失わない暗黙変換のために、ユーザーが変換ノードを手動で追加することは必須としない。
- 暗黙変換は中央の型変換レジストリへ直接変換として登録する。
- 複数段階の暗黙変換経路は自動探索しない。
- 接続を作成するときに使用する変換IDを確定し、接続データへ保存する。
- 元の情報を失う変換は暗黙変換として扱わず、専用の変換ノードを必要とする。
- 初期版では `ImageFrame`、`Float`、`Int`、`Bool`、`Vector2`、`Vector3`、`Vector4`、`Color` をポート型として提供する。
- 初期版で異なる型の間に許可する暗黙変換は `Color` と `Vector4` の相互変換だけとする。

## 設計意図

- 接続操作を簡潔にし、互換性のある値を扱うためだけの変換ノードを減らす。
- 型安全性は維持し、変換不能な接続による実行時エラーを防ぐ。
- ランタイムノードエディターで、接続可能かどうかを操作中に判断できるようにする。
