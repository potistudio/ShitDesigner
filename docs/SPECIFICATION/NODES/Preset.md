# プリセット

## 状態

基本範囲、部分プリセット方式、原子的なフレーム境界での即時適用は確定。

## 役割

ライブ中に呼び出すため、既存ノードのパラメーター値だけを名前付きで保存する。

## 確定事項

- プリセットはVJプロジェクト内に複数保存できる名前付きデータとする。
- プリセットが保存するのは、既存ノードのパラメーターの `BaseValue` だけとする。
- プリセットはノードを追加または削除しない。
- プリセットはノード間の接続を変更しない。
- プリセットはノードの有効／無効状態を変更しない。
- プリセットは `ProgramOutput` の入力接続を変更しない。
- プリセットはPreviewノードの追加、削除、接続、表示状態を変更しない。
- プリセットはVJプロジェクト全体または独立したノードグラフアセットの代わりではない。
- プリセットの呼び出しはStandaloneアプリの実行中に行える。
- 名前付き `PresetTrigger` 論理コントロールからプリセットを呼び出せる。
- 初期版で `PresetTrigger` が直接実行できる操作はプリセット呼び出しだけとし、パラメーターを直接変更しない。
- 1つの `PresetTrigger` が参照できるプリセットは最大1つとし、複数の `PresetTrigger` から同じプリセットを参照できる。
- 物理入力デバイスの割り当てを変更しても、論理コントロールとプリセットの関係を維持する。
- プリセット本体はVJプロジェクトの保存対象に含め、再読込時に復元する。
- プリセットごとに保存対象のパラメーターを選択する。
- プリセットに含まれないパラメーターは、呼出時の現在値を維持する。
- 動画Transportを含む各パラメーターは、個別にプリセット対象へ選択できる。
- プリセット対象は `NodeInstanceId` と安定した `ParameterId` で参照する。
- 呼出時は全対象を事前検証し、すべて有効な場合だけ次の評価フレーム境界で一斉に反映する。
- 1つでも検証に失敗した場合は、プリセット内のどの値も適用しない。
- ハード範囲外の値は検証失敗とせず、境界へクランプした値を適用する。
- プリセットは値を補間せず、次の評価フレーム境界で目標値へ即時変更する。
- プリセット適用後の `EffectiveValue` は、更新された `BaseValue` とその時点の論理コントロール合成式から同じ評価フレーム境界で再計算する。
- 滑らかな値変化は専用の制御またはアニメーションノードへ任せる。

## 保存概念

プリセット内の各値は、対象ノードのインスタンスとパラメーターを識別できる参照、および保存値を持つ。

```text
Preset
├─ Name
└─ ParameterValues
   ├─ NodeInstanceId + ParameterId + Value
   └─ ...
```

正式な識別、対象参照およびプロジェクト保存形式は `PresetIdentityAndEditing.md` と `VJProjectPersistence.md` へ従う。

## 設計意図

- Prefab生成、ノード破棄、接続再構築を行わず、ライブ中に軽く状態を切り替える。
- グラフ構造と演出値の切り替えを分離する。
- 物理デバイスへ直接依存せず、論理コントロールから同じ演出状態を呼び出せるようにする。
