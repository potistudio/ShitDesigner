# プリセットの識別と編集

## 状態

プリセットID、名前、並び順、カテゴリ、対象選択および参照切れの扱いは確定。

## 識別

- 各プリセットは安定したUUID v4の `PresetId` を持つ。
- 表示名は前後空白を除去した1文字以上の文字列とする。
- 表示名はVJプロジェクト内で大文字小文字を区別せず一意とする。
- 名前変更では `PresetId` を変更しない。

## 整理

- プリセットはユーザーがドラッグで変更できる整数の `SortIndex` を持つ。
- 同じ `SortIndex` の場合は表示名、次に `PresetId` で安定ソートする。
- 任意のカテゴリ文字列を1つ持てる。空文字は未分類を表す。
- 初期版ではカテゴリの階層化、タグおよび検索構文を設けない。

## 対象選択

- 編集UIはノード、パラメーターのツリーで保存対象を選択する。
- ノード単位の全選択と全解除を提供する。
- 選択時に現在の `BaseValue` をプリセット値として取り込む。
- `EffectiveValue` は取り込まない。

## 参照切れ

- 対象ノードまたはパラメーターが見つからない値もプリセットから削除せず、`Broken` 項目として保持する。
- `Broken` 項目を含むプリセットは事前検証に失敗し、どの値も適用しない。
- 編集UIは対象ID、保存値および失敗理由を表示し、項目を削除できる。
- Undoまたはノード型復旧で対象が戻った場合は自動的に再検証する。

## 設計意図

- 名前や並び替えから参照を分離する。
- 部分プリセットの対象を大量のパラメーターから選びやすくする。
- 壊れた参照を黙って無視して再現不能な部分適用を起こさない。
