# プリセット遷移ポリシー

## 状態

確定。

## 確定事項

- プリセットはパラメーター値の補間機能を持たない。
- プリセットに遷移時間またはイージング設定を保存しない。
- 検証に成功したプリセット値は、予約された次の評価フレーム境界で目標値へ即時変更する。
- `Float`、Vector、`Color`を含め、プリセット対象の型によって暗黙的な補間を行わない。
- 複数のプリセット対象値は、同じ評価フレーム境界で一斉に目標値へ変更する。
- 滑らかな値変化が必要な場合は、プリセットではなく専用の制御またはアニメーションノードで表現する。
- 専用ノードによる補間機能を追加しても、プリセットの即時適用契約は変更しない。

## 設計意図

- プリセット呼出後の値とタイミングを予測しやすくする。
- 型ごとの補間規則をプリセット機能へ持ち込まない。
- 状態の呼出と時間変化の生成を別の責務へ分ける。
- プリセットをライブ中に軽く適用できるようにする。

## 初期範囲外

- プリセット間のモーフィング
- プリセットごとの遷移時間
- プリセットごとのイージング
- Bool、Int、素材参照などの切り替えタイミング指定
