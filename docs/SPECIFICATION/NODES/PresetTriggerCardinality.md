# PresetTriggerとプリセットの割り当て数

## 状態

1つの `PresetTrigger` に割り当てられるプリセットを最大1つとし、複数の `PresetTrigger` から同じプリセットを参照できる方式は確定。

## 確定事項

- 1つの `PresetTrigger` 論理コントロールが持てるプリセット割り当ては、0個または1個とする。
- プリセットが未割り当ての `PresetTrigger` は発火できるが、プリセット適用処理を行わない。
- プリセットが割り当てられた `PresetTrigger` は、1回の発火につきそのプリセットを1回呼び出す。
- 1つの `PresetTrigger` から複数のプリセットを同時または順番に呼び出す機能は設けない。
- 複数の `PresetTrigger` から同じプリセットを参照できる。
- 1つの物理操作で複数パラメーターを変更する場合は、対象値を1つの部分プリセットへまとめる。
- 割り当て先を変更する場合は、既存のプリセット参照を新しいプリセット参照で置き換える。
- `PresetTrigger` とプリセットの割り当ては、VJプロジェクトへ保存して復元する。

## 割り当て概念

```text
PresetTrigger A ─┐
                  ├─ Preset X
PresetTrigger B ─┘

PresetTrigger C ─── Preset Y
```

## 設計意図

- 1回の発火から複数プリセットが競合する状態を作らない。
- 複数値の原子的な変更は、プリセット本体の責務として維持する。
- 同じ演出状態を複数の物理操作から呼び出せるようにする。
