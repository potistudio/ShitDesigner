# PresetTriggerによるプリセット呼び出し

## 状態

初期版で `PresetTrigger` 論理コントロールが直接実行できる操作をプリセット呼び出しだけに限定し、割り当て先を最大1つとする方針は確定。

## 役割

一度きりの物理操作から、検証済みのパラメーター集合を評価フレーム境界で原子的に適用する。

## 確定事項

- `PresetTrigger` 論理コントロールの直接ターゲットはプリセットとする。
- `PresetTrigger` はノードパラメーターを直接変更しない。
- `PresetTrigger` はMin／Max合成式へ参加しない。
- `PresetTrigger` は動画Transport、ノードの有効状態、グラフ接続、Program出力またはPreviewを直接操作しない。
- 動画Transportを含むパラメーターを変更する場合も、対象値を含むプリセットを呼び出す。
- `PresetTrigger` とプリセットの割り当ては、安定した `LogicalControlId` とプリセット参照によってVJプロジェクトへ保存する。
- 発火を受けたプリセットは、通常のプリセット呼び出しと同じ事前検証を行う。
- 検証に成功したプリセットは、次のノードグラフ評価フレーム境界で原子的に適用する。
- 検証に失敗した場合はどの値も変更せず、プリセット呼び出し失敗として操作画面へ表示する。
- `Value` 論理コントロールはプリセット呼び出しに使用せず、パラメーターのターゲット割り当てに使用する。
- 1つの `PresetTrigger` に割り当てられるプリセットは0個または1個とする。
- 複数の `PresetTrigger` から同じプリセットを参照できる。
- 複数パラメーターの変更は、1つの部分プリセットへまとめる。

## 処理概念

```text
物理入力
  ↓
PresetTrigger発火
  ↓
割り当てられたPresetを事前検証
  ↓
次の評価フレーム境界で原子的に適用
```

## 設計意図

- PresetTriggerによる状態変更を、既存のプリセット検証と原子的適用へ統一する。
- 一度の発火からパラメーターを順番に直接書き換え、途中状態が映像へ現れることを防ぐ。
- 初期版の発火アクションを限定し、操作マッピングの責務を明確にする。
