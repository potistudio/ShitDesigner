# PresetTriggerの発火と適用

## 状態

`PresetTrigger` の発火判定、再発火、同一フレーム処理および参照切れの扱いは確定。

## 発火判定

- デジタル物理入力では、非アクティブからアクティブへの立ち上がりで1回発火する。
- アクティブ状態を保持している間は再発火しない。
- 非アクティブへ戻ると再び発火可能になる。
- アナログ物理入力では、正規化値が `0.5` 以上になったときアクティブとする。
- アナログ入力の解除閾値は `0.4` とし、ヒステリシスによって境界付近の連続発火を防ぐ。
- 1つの `PresetTrigger` が同じ評価フレーム内に複数回発火しても、1回へまとめる。

## プリセット適用

- 1つの `PresetTrigger` は0個または1個のプリセットを参照する。
- 未割り当てで発火した場合は値を変更せず、操作画面へ警告を表示する。
- 同じ評価フレーム内に同じプリセットへの要求が複数届いた場合は1回へ重複排除する。
- 異なるプリセットへの要求は、入力ルーターが付与した単調増加シーケンス順で処理する。
- 各プリセットは個別に事前検証し、無効なプリセットだけを拒否する。
- 有効なプリセットはシーケンス順で同じフレーム境界の `BaseValue` 更新トランザクションへ加える。
- 複数プリセットが同じパラメーターを含む場合は、シーケンスが後のプリセット値を採用する。
- 全プリセット処理後にパラメータースナップショットを1回作り、映像へ途中状態を出さない。

## 参照切れ

- 割り当て先プリセットが削除されても `PresetId` を含む割り当てを `Broken` として保持する。
- `Broken` な `PresetTrigger` は発火時に何も適用せず、理由を操作画面へ表示する。
- 同じ `PresetId` がUndoで復元した場合は自動的に有効へ戻す。

## 履歴

- 発火成功、未割り当て、参照切れおよび適用失敗をセッション診断履歴へ記録する。
- 同じ警告の連続記録は診断ログの共通抑制規則に従う。

## 設計意図

- 押しっぱなしやアナログノイズによるプリセット連打を防ぐ。
- 同一フレームの競合を到着時刻ではなく明示的なシーケンスで再現可能にする。
- 削除操作でマッピングを暗黙に失わないようにする。
