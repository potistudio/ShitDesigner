# Preview表示方式

## 状態

確定。

## 確定事項

- 各Previewノードは、アスペクト比の異なる映像を表示領域へ合わせる表示方式をパラメーターとして持つ。
- 表示方式は `Fit`、`Fill`、`Stretch` の3種類とする。
- Previewノードごとに表示方式を個別設定できる。
- Previewノードの既定表示方式は `Fit` とする。
- 表示方式パラメーターはVJプロジェクトの保存対象に含め、再読込時に復元する。
- 表示方式の変更はPreview終端だけへ適用し、共有された上流ノードを再評価しない。
- `Fit` は映像全体とアスペクト比を維持して表示する。
- `Fill` はアスペクト比を維持して表示領域を埋め、はみ出した部分を切り取る。
- `Stretch` は表示領域に合わせて縦横を独立に拡縮する。

## 設計意図

- Previewごとの確認目的に合わせて見え方を選択できるようにする。
- 映像全体を確認できる安全な `Fit` を既定値とする。
- 表示方法の変更によって上流の映像生成負荷が増えないようにする。
