# Preview出力

## 状態

基本契約、複数Preview、サムネイル／パネル表示、診断表示および自動性能制御まで確定。

## 役割

操作者がノードグラフの映像と状態を確認するためのPreviewを提供する。

## 確定事項

- 初期必須構成として、Program映像と同時に操作用Previewを提供する。
- 表示中のPreviewは、グラフ評価を開始する出力ターゲットの1つである。
- Previewが要求する上流ノードは、Program出力と同じ評価フレーム内で評価する。
- ProgramとPreviewが同じ上流ノードを要求する場合、同一フレームの評価結果を共有する。
- Preview対象まで `Blocked` 状態が伝播した場合、操作用Previewへエラー表示を重ねる。
- Previewの診断表示はProgram映像へ混入させない。
- エラー表示には、原因となった未接続ポートまたは上流ノードを特定できる情報を使用する。
- Previewは通常の追加・削除可能な終端ノードとしてグラフ内へ配置する。
- 複数のPreviewノードを配置し、複数映像を同時表示できる。
- 表示中のPreviewノードだけをPreview評価の起点とする。
- Previewノードと入力接続はVJプロジェクトへ保存する。
- Program出力をPreviewより優先し、負荷が高い場合はPreviewの更新頻度または解像度を自動的に下げる。

## 設計意図

- Program映像を汚さずに、操作者が問題の発生と原因を確認できるようにする。
- ProgramとPreviewの共通処理を重複評価しない。
