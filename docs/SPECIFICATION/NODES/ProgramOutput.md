# Program出力

## 状態

基本契約、固定ノード修復、Unity Display提示、最後の正常フレームおよび性能警告まで確定。

## 役割

ノードグラフの最終映像を観客向けのProgram映像として出力する。

## 確定事項

- 初期必須構成ではProgram映像を1系統提供する。
- Program出力は、グラフ評価を開始する出力ターゲットの1つである。
- 初期版のProgram内部映像は1920×1080固定、更新目標は60fpsとする。
- Program出力が現在フレームの有効な `ImageFrame` を取得できた場合、その映像を表示し、最後の正常フレームとして保持する。
- Program出力まで `Blocked` 状態が伝播した場合、新しい映像へ更新せず最後の正常フレームを表示し続ける。
- Program出力が一度も正常フレームを取得していない状態で `Blocked` になった場合は、黒い映像を表示する。
- Program映像には、Blocked状態やエラーの診断表示を重ねない。
- 最後の正常フレームを表示している間も、内部状態は正常更新中と区別する。
- `ProgramOutput` はグラフ内に必ず1つ存在するシステム所有ノードとする。
- `ProgramOutput` ノードは削除、複製、追加できないが、入力接続は実行中に変更できる。
- `ProgramOutput` ノードの入力接続はVJプロジェクトへ保存する。
- Program出力から1920×1080の要求解像度を上流へ伝播する。
- 内部Linear映像をProgram表示先が要求する色空間へ終端で変換する。
- Programの最終出力はLDRとする。
- 内部HDRプロジェクトでは、Program終端でHDR映像をLDRへトーンマッピングする。
- Program終端のLDR映像データはPremultiplied Alphaを保持する。
- 通常の画面表示ではProgram映像を黒背景へ合成して提示し、Alphaを保持した元データは変更しない。
- Programは選択したUnity Displayへ全画面表示し、追加Displayがない場合は操作画面内のProgramモニターへ表示する。
- 現在フレームを取得できず最後の正常フレームを表示中の状態名は `HoldingLastFrame` とする。

## 設計意図

- ライブ中の一時的な切断や編集ミスによる黒画面への急な切り替わりを防ぐ。
- 操作用の診断情報を観客向け映像へ表示しない。
- 問題発生中であることを内部では維持し、復旧後に新しい正常フレームへ更新できるようにする。
