# Program出力の提示と運用

## 状態

Program入力名、配置、保存修復、表示先、最後の正常フレームおよび性能警告は確定。

## 固定ノード

- 型IDは `system.program_output`、入力Port IDは `image`、表示名は `Image` とする。
- ノードは削除・複製できないが、ノードエディター上の位置は移動できる。
- 新規プロジェクトではグラフ表示領域の右側中央へ配置する。
- 保存データに存在しない場合は新規作成して警告する。
- 複数存在する場合は保存順で最初の1つを正規ノードとし、余分なものはデータを保持した `UnknownNode` へ変換する。

## 提示先

- Programの内部映像は常に1920×1080・60fpsを目標に生成する。
- 初期版は選択したUnity Displayへ全画面表示する。
- 2台目以降のDisplayがない場合は、Standalone操作画面内のProgramモニターへ表示する。
- 外部API、NDI、Spoutおよび録画への出力は初期版に含めない。

## 障害時

- 現在フレームを取得できない状態名は `HoldingLastFrame` とする。
- 最後の正常フレームがあれば、それを表示し続ける。
- 正常フレームが一度もない場合は不透明黒を表示する。
- Program映像上へ診断文字を重ねず、操作画面側へ状態と原因を表示する。

## 性能監視

- 実測Program FPS、CPU Frame Time、GPU Frame Timeを操作画面へ表示する。
- 60フレーム連続でProgram FPSが59fps未満、またはFrame Timeが16.67msを超えた場合に警告する。
- 警告はPreview抑制を開始させるが、Program解像度と目標更新頻度は下げない。

## 設計意図

- システム所有ノードの破損した保存状態を自動修復する。
- 映像障害を観客向けProgramへ診断画面として出さない。
- 初期版の出力経路をUnity Displayへ限定する。
