# 登録型2D描画ノード

## 状態

確定。3D描画ノードと同じ登録、保存、バージョニング方式を使用する。

## 確定事項

- 2D表現ごとに、独立した2D描画ノード型を定義する。
- 各2D描画ノード型は、保存後も変わらない安定した型IDを持つ。
- 各2D描画ノード型は、専用2D空間を生成するPrefabまたは同等の生成定義を持つ。
- 各2D描画ノード型は、自身が提供する入力ポート、出力ポート、パラメーターを定義する。
- 各2D描画ノード型は、他の種類と同じ共通 `NodeTypeRegistry` へ2Dカテゴリとして登録する。
- 同じ2D描画ノード型を、グラフ内へ複数インスタンス配置できる。
- 各インスタンスは専用2D空間とパラメーター状態を個別に持つ。
- VJプロジェクトには、2D描画ノードの型ID、インスタンスID、`SchemaVersion`、パラメーター、ポート状態を保存する。
- VJプロジェクトへPrefab、GameObject階層、Canvas階層そのものを直列化しない。
- VJプロジェクト読込時は型IDから登録定義を解決し、Prefabまたは生成定義から専用2D空間を復元する。
- 各2D描画ノード型は固有の `SchemaVersion` と段階的な状態移行処理を持つ。
- 新しい2D描画ノード型を追加しても、既存ノード型またはノードグラフの共通保存構造を変更しない。

## 3D描画ノードとの共通性

- 表現ごとに独立した登録ノード型を作る。
- ノードインスタンスごとに描画空間と状態を分離する。
- 型IDとインスタンス状態を保存し、Unityオブジェクト階層そのものは保存しない。
- 共通 `NodeTypeRegistry`、Factory、ポート、パラメーター、`SchemaVersion` の契約を使用する。
