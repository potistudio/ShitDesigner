# 登録型Shaderノード

## 状態

確定。3D／2D描画ノードと同じ登録、保存、バージョニング方式を使用する。

## 確定事項

- Shader表現ごとに、独立したShaderノード型を定義する。
- 各Shaderノード型は、保存後も変わらない安定した型IDを持つ。
- 各Shaderノード型は、使用するShaderまたはMaterialを明示的に定義する。
- 各Shaderノード型は、自身が提供する入力ポート、出力ポート、公開パラメーターとShaderプロパティの対応を明示的に定義する。
- Shaderプロパティからポートやパラメーターを実行時に自動生成しない。
- 各Shaderノード型は、他の種類と同じ共通 `NodeTypeRegistry` へShaderカテゴリとして登録する。
- 同じShaderノード型を、グラフ内へ複数インスタンス配置できる。
- 各インスタンスはMaterial状態と公開パラメーターを個別に持つ。
- VJプロジェクトには、Shaderノードの型ID、インスタンスID、`SchemaVersion`、パラメーター、ポート状態を保存する。
- VJプロジェクトへShaderまたはMaterialアセットそのものを直列化しない。
- VJプロジェクト読込時は型IDから登録定義を解決し、ShaderまたはMaterial定義からインスタンスを復元する。
- 各Shaderノード型は固有の `SchemaVersion` と段階的な状態移行処理を持つ。
- 新しいShaderノード型を追加しても、既存ノード型またはノードグラフの共通保存構造を変更しない。
- GeneratorまたはEffectの役割はノード型定義へ固定する。

## 3D／2D描画ノードとの共通性

- 表現ごとに独立した登録ノード型を作る。
- 型IDとインスタンス状態を保存し、Unityアセットそのものは保存しない。
- 共通 `NodeTypeRegistry`、Factory、ポート、パラメーター、`SchemaVersion` の契約を使用する。
