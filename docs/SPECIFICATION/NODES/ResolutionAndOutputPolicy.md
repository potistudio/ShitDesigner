# 解像度要求と出力サイズ

## 状態

解像度統合、アスペクト優先順位、ノード倍率、切り替え、縮小フィルターおよびProgramサイズは確定。

## Program

- 初期版のProgram内部解像度は `1920×1080` 固定、更新目標は60fpsとする。
- 実行中およびプロジェクト設定で別解像度を選択する機能は初期版に含めない。

## 要求統合

- 優先順位はProgram、フォーカス中Preview、その他の表示中Previewの順とする。
- その他のPreview間では最後にフォーカスされた時刻、次に `NodeInstanceId` で安定順位を決める。
- 共有ノードのアスペクト比は最高優先度の要求を採用する。
- 幅と高さは、採用アスペクト比を維持しながら全要求の幅・高さ以上になる最小サイズへ統合する。
- 同じ画素数でも幅と高さが異なる場合は上記の優先順位で結果が一意になる。

## ノード処理

- 初期版の映像ノードは伝播された要求解像度をそのまま採用する。
- ノード固有の固定解像度または倍率指定は初期版で設けない。
- Shader Effectは入力Texture寸法ではなく要求出力解像度で実行し、入力をサンプリングする。
- 動画と既定映像の拡縮はBilinearフィルターを使用する。
- 解像度変更は評価フレーム境界でLease切り替え手順へ渡す。

## Preview終端

- `Fit` の余白は透明黒 `(0,0,0,0)` とする。
- `Fill` は映像中央を基準に切り取る。
- `Stretch` はアスペクト比を維持しない。
- Preview UIの背景はチェッカーまたは黒を選べるが、映像データ自体の余白は透明黒のままとする。

## 設計意図

- Programの最低基準を設定差で崩さない。
- 共有ノードを複数サイズで再評価せず、必要条件を満たす1つの要求へ統合する。
- ノード固有解像度の複雑さを初期版へ入れない。
