# UnknownNode

## 状態

基本契約、正式型ID、対象ケース、自動復元および手動復元操作まで確定。

## 発生条件

VJプロジェクトに保存されたノード型IDが、現在の `NodeTypeRegistry` に登録されていない場合に使用する。

## 確定事項

- 未登録の型IDを持つノードが存在しても、VJプロジェクト全体の読込を中止しない。
- 未登録ノードを削除せず、`UnknownNode` プレースホルダーとしてグラフへ配置する。
- `UnknownNode` は、元の型ID、`SchemaVersion`、未解釈の保存状態を変更せず保持する。
- `UnknownNode` は、保存データに含まれる入力ポート、出力ポート、接続を保持する。
- `UnknownNode` のノードエディター上の位置など、共通ノード状態も保持する。
- `UnknownNode` は元ノードの評価処理を実行せず、現在フレームの出力値を生成しない。
- `UnknownNode` の出力を必須入力として使用する下流ノードは `Blocked` 状態になる。
- `UnknownNode` の出力を任意入力として使用する下流ノードは、既定値へフォールバックする。
- ノードエディターは、未登録の型IDと評価できない理由を表示する。
- `UnknownNode` を含むVJプロジェクトを保存しても、保持している元ノードの生データ、ポート、接続を失わない。
- 対応するノード型が `NodeTypeRegistry` へ追加された後、保持データから本来のノードへ復元できるようにする。

## 設計意図

- 1種類のノード不足によって、プロジェクト内の正常なグラフや素材まで開けなくなることを防ぐ。
- 未登録ノードを含むプロジェクトを保存しても、将来の復旧可能性を維持する。
- 別PCや異なるアプリ構成へプロジェクトを移動した場合に、欠けているノード型を特定できるようにする。
