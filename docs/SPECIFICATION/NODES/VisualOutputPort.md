# 映像出力ポート

## 状態

確定。

## 確定事項

- 映像を出力するすべてのノードは、`Image` という名前の主出力ポートを1つ持つ。
- `Image` は必須ポートであり、省略または別名への変更はできない。
- `Image` は、映像実体の `RenderTexture` と付随情報を持つ `ImageFrame` を出力する。
- ノード種別は、`Image` に加えて任意の名前付き出力ポートを定義できる。
- 追加出力は必須ではなく、ノード種別の機能に応じて定義する。
- 1つの出力ポートを複数の入力ポートへ接続できる。
- 接続先は共有された出力を読み取り専用として扱う。

## 設計意図

- 基本的な映像接続では、ノード種別に関係なく `Image` を接続すればよい。
- 単純なノードは1出力のまま保てる。
- 将来、DepthやMaskなどが必要になっても、主出力の契約を変更せず追加できる。
- 同じ映像を複数箇所で利用しても、出力元の映像生成を重複させない。
